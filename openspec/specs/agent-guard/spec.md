# agent-guard Specification

## Purpose
定义化学助教回答的安全边界：四条红线必须同时由系统提示与发送前输出检查保障，输出检查按句缓冲、命中后给出可继续对话的拒绝或安全回复，并保持流式事件契约不变。

## Requirements

### Requirement: 四条红线固定写入系统提示

系统提示 MUST 写死四条红线：不代替学生完成考试中的作答、不泄露其他学生的成绩与信息、不给危险实验操作建议、不使用羞辱或贬低性表达。四条红线 MUST 位于系统提示的固定段，MUST NOT 随场景或人设替换，MUST NOT 只在某个场景下出现。

#### Scenario: 任意场景都带红线
- **WHEN** 学生从练习、错题或对话入口发起请求
- **THEN** 系统提示都包含同一段四条红线

#### Scenario: 换人设不冲淡红线
- **WHEN** 连续答错触发鼓励型
- **THEN** 系统提示仍保留四条红线且顺序不变

#### Scenario: 老师对话也带红线
- **WHEN** 老师发起对话
- **THEN** 系统提示同样包含四条红线

### Requirement: 考试中按服务端状态拦截解题

学生发起对话时，服务端 MUST 先查该学生是否存在 `in_progress` 的作答记录，MUST NOT 依赖学生是否说明正在考试。存在记录时，系统提示 MUST 加入考试约束，输出检查 MUST 拦截答案、选项与解题步骤；命中时 MUST 拒绝并说明考完可以一起看。

#### Scenario: 学生明说在考试
- **WHEN** 学生说“我正在考试，这题选哪个”
- **THEN** 拒绝给出答案、选项或步骤，并说明考完可以一起看

#### Scenario: 学生只粘贴题干
- **WHEN** 学生没有说明在考试，但服务端查到作答中记录
- **THEN** 仍按考试处理，不给出解题步骤

#### Scenario: 没有作答中记录
- **WHEN** 学生没有作答中的卷子
- **THEN** 不插入考试约束，正常回答解题请求

#### Scenario: 考试结束后再问
- **WHEN** 作答记录不再是进行中
- **THEN** 可以正常讲解该题

### Requirement: 不泄露其他学生的成绩与信息

工具 MUST 只返回当前身份可见的数据；输出检查 MUST 再扫描回答中是否出现当前用户无权看到的其他学生姓名、分数或成绩。命中时 MUST 拒绝并引导查看自己的数据，MUST NOT 透露被问到的名字是否存在。

#### Scenario: 学生问别人的分数
- **WHEN** 学生问“张三考了多少分”
- **THEN** 拒绝并说明可以看自己的弱项，不确认张三是否存在

#### Scenario: 模型自己编名字
- **WHEN** 回答里出现当前学生无权看到的其他学生姓名或分数
- **THEN** 输出检查拦截并替换为拒绝话术

#### Scenario: 工具只给本人数据
- **WHEN** 学生调用看学生画像或看考试结果
- **THEN** 工具只返回当前学生的数据

#### Scenario: 老师问别班
- **WHEN** 老师问别的班的情况
- **THEN** 拒绝，只允许当前班级

### Requirement: 不给危险实验操作建议

系统提示 MUST 要求拒绝危险实验操作并给出安全做法；输出检查 MUST 扫描危险操作模式。命中时 MUST 拒绝执行该操作，并 MUST 给出安全的替代做法或说明不能试，MUST NOT 只回复“违反安全规定”。

#### Scenario: 直接问危险操作
- **WHEN** 学生问“能不能直接闻一下氯气”
- **THEN** 拒绝并说明正确做法是扇闻

#### Scenario: 正常知识提问不误伤
- **WHEN** 学生问“氯气为什么有毒”
- **THEN** 正常解释，不按危险操作拒绝

#### Scenario: 输出含危险步骤
- **WHEN** 模型回答里出现直接闻、加热等危险操作步骤
- **THEN** 输出检查拦截并替换为安全回复

### Requirement: 不使用羞辱或贬低性表达

系统提示 MUST 禁止羞辱或贬低性表达；输出检查 MUST 扫描回答中的贬低措辞，命中时 MUST 丢弃该片段并改写成中性表述。学生使用侮辱性语言时，助教 MUST NOT 跟着对骂，MUST 平静说明并继续当前的事。

#### Scenario: 学生连续答错
- **WHEN** 学生连续答错三次以上
- **THEN** 回答不出现“这么简单都不会”这类话

#### Scenario: 学生辱骂助教
- **WHEN** 学生使用侮辱性语言
- **THEN** 助教不跟着对骂，平静说明并继续当前任务

#### Scenario: 模型输出贬低句
- **WHEN** 模型生成了贬低性表达
- **THEN** 输出检查丢弃该片段并改写成中性表述

### Requirement: 输出检查在发送前按句缓冲

模型正文 MUST 按句或小段缓冲，缓冲区内容 MUST 先通过四条红线检查再作为 `text` 事件发送。命中红线时 MUST NOT 发送命中片段及其后的模型正文，MUST 改为发送一条对应的安全回复，并 MUST 正常发送 `end`。检查 MUST NOT 额外调用模型；未命中时 MUST 继续按小段增量发送，MUST NOT 等整段回答生成完再发。

#### Scenario: 干净内容继续流式
- **WHEN** 模型连续生成多个安全句子
- **THEN** 客户端按小段收到 `text`，不等整段完成

#### Scenario: 命中后停止原文
- **WHEN** 缓冲片段命中红线
- **THEN** 客户端不再收到该片段及其后的模型原文

#### Scenario: 命中后正常结束
- **WHEN** 输出检查用安全回复替换违规内容
- **THEN** 本轮仍以恰好一个 `end` 结束

#### Scenario: 检查不额外调模型
- **WHEN** 本轮回答通过输出检查
- **THEN** 不产生新的模型调用

### Requirement: 拒绝话术要给出下一步

红线命中的拒绝 MUST 同时说明为什么不行与接下来能做什么，MUST NOT 只返回“无法回答”“无权访问”或“违反安全规定”。

#### Scenario: 考试中拒绝
- **WHEN** 考试中问答案被拒
- **THEN** 回答说明考完可以一起看

#### Scenario: 问别人成绩被拒
- **WHEN** 学生问别人的成绩被拒
- **THEN** 回答说明可以看自己的弱项

#### Scenario: 危险操作被拒
- **WHEN** 危险操作被拒
- **THEN** 回答给出安全做法
