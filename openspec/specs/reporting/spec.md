# reporting Specification

## Purpose

把已判分考试的逐题作答按知识点汇总成学生能看的弱项：固定错误率口径、样本门槛、前三排序，并区分「没有学习记录」与「暂时没有可统计的弱项」。

## Requirements

### Requirement: 错误率口径
错误率 MUST 等于错题数除以作答数。统计 MUST 读已判分考试的逐题作答和练习记录两处，每条作答各算一次；同一道题答三次错两次时，分子 MUST 是 2，分母 MUST 是 3。一道题属于多个知识点时，MUST 在每个知识点的分子分母里各算一次。没有关联知识点的题、未判分记录、复习作答 MUST NOT 进入统计。练习记录 MUST 按它作答的那道题关联的知识点计入。

#### Scenario: 同一题多次作答各算一次
- **WHEN** 学生对一道题答了三次、错两次
- **THEN** 这道题所属知识点的作答数是 3，错题数是 2

#### Scenario: 一题多知识点各算一次
- **WHEN** 一道同时属于两个知识点的题答错了
- **THEN** 两个知识点各自的错题数都加 1，作答数也都加 1

#### Scenario: 未挂知识点的题不计
- **WHEN** 学生答错一道没有关联任何知识点的题
- **THEN** 任何知识点的错误率都不变

#### Scenario: 未判分记录不计
- **WHEN** 一条作答记录停在已交卷且分数为空
- **THEN** 它的逐题作答不进入任何知识点的分子或分母

#### Scenario: 复习作答不计
- **WHEN** 学生在复习里答错一道题
- **THEN** 任何知识点的错误率都不变

#### Scenario: 未作答按错计入
- **WHEN** 学生交白卷，卷内每道题都记了空答案并按错判
- **THEN** 这些题按错题计入各自知识点

#### Scenario: 练习答错计入
- **WHEN** 学生练习时答错一道挂着知识点的题
- **THEN** 该知识点的作答数加 1，错题数加 1

#### Scenario: 练习答对计入分母
- **WHEN** 学生练习时答对一道挂着知识点的题
- **THEN** 该知识点的作答数加 1，错题数不变

#### Scenario: 考试与练习合并计数
- **WHEN** 学生对同一知识点先考试答错一次、再练习答对一次
- **THEN** 该知识点的作答数是 2，错题数是 1，错误率是 50%

#### Scenario: 练习未挂知识点不计
- **WHEN** 学生练习一道没有关联任何知识点的题
- **THEN** 任何知识点的错误率都不变

### Requirement: 弱项前三与样本门槛
弱项排名 MUST 只计算作答数不少于 2 的知识点；作答数 MUST 按考试逐题作答与练习记录合并计算。错误率为 0 的知识点 MUST NOT 进入弱项。排序 MUST 先按错误率降序，错误率相同时按作答数降序，再相同时按知识点 ID 升序；最多 MUST 返回 3 个。错误率 MUST 以百分比返回并保留一位小数；每条 MUST 含知识点 ID、名称、作答数、错题数和错误率。

#### Scenario: 样本不足不进排名
- **WHEN** 一个知识点只有 1 次作答且答错
- **THEN** 它的错误率虽是 100%，但不进入弱项排名

#### Scenario: 样本够但全对不占前三
- **WHEN** 一个知识点有 2 次作答且全对，另外三个知识点的错误率都高于 0
- **THEN** 这个知识点不进入前三

#### Scenario: 全对且没有更高错误率也不进弱项
- **WHEN** 一个知识点有 2 次作答且全对，它是唯一达到样本门槛的知识点
- **THEN** 弱项列表为空，掌握度仍按这个知识点计算

#### Scenario: 错误率相同按作答数排
- **WHEN** 两个知识点的错误率相同，一个作答 8 次、一个作答 4 次
- **THEN** 作答 8 次的排在前面

#### Scenario: 最多三个
- **WHEN** 五个知识点的作答数都达到门槛
- **THEN** 只返回错误率最高的三个

#### Scenario: 百分比一位小数
- **WHEN** 一个知识点作答 3 次、错 2 次
- **THEN** 错误率返回 66.7

#### Scenario: 考试与练习合起来达到门槛
- **WHEN** 一个知识点在考试里作答 1 次、在练习里作答 1 次
- **THEN** 作答数是 2，达到样本门槛

### Requirement: 无数据状态
学生没有任何已判分的逐题作答、也没有任何练习记录时，学生报告 MUST 返回 `has_data` 为 false、弱项列表为空、掌握度为 0 且带无数据标记、最近五次分数为空、待复习数按实际任务返回；页面 MUST 显示「还没有学习记录」，MUST NOT 显示「掌握度 0」或分数 0。学生有作答事实、但没有知识点达到样本门槛时，MUST 返回 `has_data` 为 true 和空弱项列表，掌握度 MUST 带无数据标记，页面 MUST 显示「暂无可统计的弱项」，MUST NOT 显示「还没有学习记录」。

#### Scenario: 新学生没有学习记录
- **WHEN** 一个还没有考过试、也没有练习过的学生请求报告
- **THEN** 返回 has_data=false、空弱项、掌握度 0 带无数据标记、空分数列表

#### Scenario: 只有练习记录也算有学习记录
- **WHEN** 一个没有考试记录、但练过题的学生请求报告
- **THEN** 返回 has_data=true，并按练习记录计算弱项和掌握度

#### Scenario: 有作答但没挂知识点
- **WHEN** 学生考过试或练过题，但作答的题都没有关联知识点
- **THEN** 返回 has_data=true 和空弱项，掌握度带无数据标记，页面显示「暂无可统计的弱项」

#### Scenario: 有作答但样本不足
- **WHEN** 学生只做过一道题（考试或练习），且它关联的知识点作答数不到 2
- **THEN** 返回 has_data=true 和空弱项，掌握度不可计算，不把 100% 当成弱项

### Requirement: 弱项的可见范围
自助弱项接口 MUST 只允许学生读取自己的弱项；老师请求该接口 MUST 返回 403 且不返回任何统计。管理员 MUST 能指定学生读取其弱项；未指定学生 MUST 返回 400；学生不存在 MUST 返回 404。老师读取学生报告 MUST 走班级范围的学生报告接口，按「只能看自己带的班」判定，MUST NOT 复用自助弱项接口。

#### Scenario: 学生只看自己的
- **WHEN** 学生请求弱项
- **THEN** 只统计这名学生自己的作答

#### Scenario: 老师没有弱项入口
- **WHEN** 老师请求自助弱项接口
- **THEN** 返回 403，不返回任何统计

#### Scenario: 管理员指定学生
- **WHEN** 管理员带学生 ID 请求弱项
- **THEN** 返回该学生的弱项

#### Scenario: 管理员不指定学生
- **WHEN** 管理员不带学生 ID 请求学生弱项
- **THEN** 返回 400，不返回统计

#### Scenario: 指定的学生不存在
- **WHEN** 管理员用一个不存在的学生 ID 请求弱项
- **THEN** 返回 404，不返回统计

### Requirement: 合并后重算
弱项 MUST 每次请求现算，MUST NOT 读缓存或存快照。知识点合并后再次请求，MUST 按合并后的目标知识点重新汇总；合并前的源知识点 MUST NOT 再出现在结果里。练习记录 MUST 按合并后的题目关联重新计入，MUST NOT 重复或丢失。

#### Scenario: 合并两个知识点后重算
- **WHEN** 两个知识点各有一些作答，老师把它们合并成一个，然后学生刷新弱项
- **THEN** 两个知识点的作答数与错题数合并在目标知识点下，源知识点不再出现

#### Scenario: 合并后练习记录重新计入
- **WHEN** 两个知识点各有考试与练习作答，老师把它们合并成一个
- **THEN** 目标知识点的作答数与错题数包含两边的考试和练习记录，没有重复行

### Requirement: 掌握度口径
掌握度 MUST 等于达到样本门槛的知识点的平均正确率乘以 100。每个知识点的正确率 MUST 等于 1 减去错误率；知识点之间 MUST 等权平均，MUST NOT 用总答对数除以总作答数。只算作答数不少于 2 的知识点，作答口径 MUST 与错误率一致：已判分考试的逐题作答与练习记录合并、复习作答不计。结果 MUST 以百分比返回并保留一位小数。

#### Scenario: 知识点等权平均
- **WHEN** 四个知识点的正确率分别为 37.5%、50.0%、50.0%、100.0% 且都达到样本门槛
- **THEN** 掌握度返回 59.4，不是按总答对数算出的 50.0

#### Scenario: 全对的知识点参与掌握度
- **WHEN** 一个知识点有 2 次作答且全对，它是唯一达到门槛的知识点
- **THEN** 掌握度返回 100.0

#### Scenario: 样本不足不参与
- **WHEN** 一个知识点只有 1 次作答
- **THEN** 它的正确率不进入掌握度的平均

#### Scenario: 一题多知识点各算一次
- **WHEN** 一道同时属于两个知识点的题答错了
- **THEN** 两个知识点的错误率各加一次，掌握度按两边各自的知识点正确率计算

#### Scenario: 复习与未判分不计
- **WHEN** 学生只在复习里答过题，或只有已交卷但未判分的考试
- **THEN** 这些作答不改变掌握度

### Requirement: 学生报告汇总
学生报告 MUST 一次返回弱项前三、掌握度、最近五次分数和待复习数四块，MUST 每次请求现算，MUST NOT 读缓存或存快照。四块 MUST 使用同一份作答事实口径；任何一块无数据时 MUST NOT 用 0 或空图表伪装成有数据。

#### Scenario: 一次返回四块
- **WHEN** 学生打开报告
- **THEN** 返回弱项列表、掌握度、最近五次分数和待复习数，不需要额外请求

#### Scenario: 修改数据后刷新
- **WHEN** 学生做完一道练习题后重新打开报告
- **THEN** 弱项和掌握度按新的作答事实重新计算

### Requirement: 最近五次分数
最近五次分数 MUST 只取已判分的考试，按判分时间倒序取最多五条，再按时间正序返回；已交卷但未判分的记录 MUST NOT 计入。每条 MUST 含卷子标题、分数和判分时间。判分时间相同时 MUST 按记录先后稳定排序。

#### Scenario: 只取最近五次
- **WHEN** 学生有六次已判分考试
- **THEN** 只返回判分时间最近的五次，并按时间正序排列

#### Scenario: 未判分不算
- **WHEN** 学生有一次已交卷但判分没完成的考试
- **THEN** 这次考试不出现在最近五次分数里

#### Scenario: 不足五次返回全部
- **WHEN** 学生只有两次已判分考试
- **THEN** 返回这两次，不补 0 分

### Requirement: 待复习数
待复习数 MUST 等于当前学生级别 0–4、且到期日不晚于当前 UTC+8 业务日期的复习任务条数。逾期任务 MUST 计入；级别 5 已出队 MUST NOT 计入；到期日在未来的 MUST NOT 计入。

#### Scenario: 今天和逾期都算
- **WHEN** 学生有三条任务：今天到期、昨天到期、明天到期
- **THEN** 待复习数是 2

#### Scenario: 出队不计
- **WHEN** 一条任务已到第 5 级并出队
- **THEN** 它不计入待复习数

### Requirement: 班级报告按考试视图
班级按考试视图 MUST 先列出该班考过的考试，选中一次考试后 MUST 返回名单人数、提交情况、逐题正确率和未交名单。考试列表 MUST 按发布时的班级快照去重卷子，每条 MUST 含卷子标题、发布时间、题数和名单人数。提交情况 MUST 分已交卷、作答中、还没开始三类，已交卷 MUST 含已交卷未判分与已判分；三类之和 MUST 等于名单人数。

#### Scenario: 提交情况三数相加等于名单
- **WHEN** 一个班发布时 60 人，已交卷 52、作答中 3、还没开始 5
- **THEN** 名单人数是 60，三类之和是 60

#### Scenario: 转班学生仍算原班
- **WHEN** 一名学生参加考试后转到别的班
- **THEN** 他的作答仍计入原班的名单人数和提交情况

#### Scenario: 重复发布只补缺
- **WHEN** 同一份卷子对同一个班再发布一次
- **THEN** 名单人数不重复增加，只补没有作答记录的学生

#### Scenario: 没有考试记录
- **WHEN** 一个新建班还没有任何已发布考试
- **THEN** 考试列表为空，页面显示「还没有考试记录」，不画图

### Requirement: 班级逐题正确率
班级逐题正确率 MUST 按卷内题目顺序返回每题的正确人数、已判分人数和正确率。分母 MUST 只含已判分记录，未判分记录 MUST NOT 进入分母；空白答案 MUST 按错题计入；分母为 0 时 MUST 返回空值并显示为「—」，MUST NOT 显示 0%。正确率 MUST 以百分比返回并保留一位小数。

#### Scenario: 未判分不进分母
- **WHEN** 60 人中 52 人已判分、8 人已交卷但判分没完成
- **THEN** 每道题的分母是 52，不是 60

#### Scenario: 白卷按错计
- **WHEN** 学生交白卷且判分完成
- **THEN** 卷内每道题都计入分母并计为答错

#### Scenario: 无人判分
- **WHEN** 一次考试的所有交卷都还没判分
- **THEN** 每道题的正确率返回空值，页面显示「—」

### Requirement: 未交名单
班级按考试视图 MUST 返回还没开始和作答中的学生姓名与状态，供讲评课点名。名单 MUST 来自发布时的班级快照；已交卷学生 MUST NOT 出现在未交名单里；转出该班的学生只要当时有作答记录且未交卷，MUST 仍然出现。

#### Scenario: 点名未交
- **WHEN** 一次考试有 3 人作答中、5 人还没开始
- **THEN** 未交名单包含这 8 人的姓名和各自状态

#### Scenario: 已交卷不出现
- **WHEN** 学生已经交卷
- **THEN** 他不出现在未交名单里

### Requirement: 班级报告按知识点视图
班级按知识点视图 MUST 返回全班知识点错误率分布、每个学生的最近一次分数与错题数、这个班考过的考试次数。全班错误率 MUST 把所有学生的考试作答合在一起算，分子分母相加，MUST NOT 对每个学生的错误率取平均。错题数 MUST 按题去重，同一道题多次答错只算一条。没有作答的学生 MUST 显示「未作答」，已交卷但还没判分的学生 MUST 显示「判分中」，两者 MUST NOT 当成 0 分。

#### Scenario: 全班错误率按作答合并
- **WHEN** 一个学生作答 1 次错 1 次，另一个学生作答 30 次错 10 次
- **THEN** 全班错误率是 11/31，不是 (100%+33.3%)/2

#### Scenario: 错题数按题去重
- **WHEN** 学生同一道题在两次考试里都答错
- **THEN** 错题数只加 1

#### Scenario: 没作答的学生
- **WHEN** 班里一名学生一次考试都没参加
- **THEN** 学生表里显示「未作答」，不显示 0 分

#### Scenario: 判分中不显示未作答
- **WHEN** 学生已经交卷，但这次考试还没判分
- **THEN** 学生表里显示「判分中」，不显示「未作答」或 0 分

#### Scenario: 没考过试的班
- **WHEN** 班级还没有已判分考试
- **THEN** 页面显示「还没有考试记录」，不显示 0

### Requirement: 班级报告的数据范围
班级报告 MUST 只统计已判分考试；未判分记录的逐题作答 MUST NOT 进入逐题正确率、知识点错误率和学生分数，但仍 MUST 在提交情况中按已交卷计数。统计 MUST 按发布时的班级快照归集，MUST NOT 按学生当前班级重算。练习记录 MUST NOT 进入班级报告。知识点合并后再次打开班级报告，MUST 按合并后的目标知识点重新汇总。

#### Scenario: 未判分不进入正确率与知识点
- **WHEN** 一条作答记录停在已交卷且分数为空
- **THEN** 它的逐题作答不进入逐题正确率、知识点错误率和学生分数

#### Scenario: 练习不进入班级报告
- **WHEN** 班级里的学生做了练习题
- **THEN** 班级报告的名单、提交情况、逐题正确率和知识点分布都不变

#### Scenario: 转班不重算历史
- **WHEN** 学生转班后老师打开原班的班级报告
- **THEN** 原班的历史数字保持不变

#### Scenario: 合并知识点后重算
- **WHEN** 老师把两个知识点合并，然后刷新班级报告
- **THEN** 两个知识点的作答合并在目标知识点下，源知识点不再出现

### Requirement: 班级报告的可见范围
班级报告 MUST 只返回老师自己带的班；老师请求非本班 MUST 返回 403 且不返回任何统计。学生 MUST 返回 403；管理员 MUST 能看全部班。老师可选的班级列表 MUST 只含自己带的班。前端隐藏入口 MUST NOT 代替服务端判定。

#### Scenario: 老师看别班被拒
- **WHEN** 老师请求自己未带的另一个班的报告
- **THEN** 返回 403，不返回任何统计

#### Scenario: 学生看班级报告被拒
- **WHEN** 学生请求班级报告
- **THEN** 返回 403

#### Scenario: 管理员看全部班
- **WHEN** 管理员请求任一班的报告
- **THEN** 允许

### Requirement: 老师下钻学生报告
老师 MUST 能从班级报告的学生行读取该生报告；页面入口 MUST 只出现在该生当前所在的那个班的报告里。老师直接读取学生报告时，读取权限 MUST 满足：该生当前属于这位老师带的班。学生已经转出该班时，原班报告 MUST 保留其历史考试数字，但 MUST NOT 提供报告入口。学生 MUST 只能看自己的报告；管理员 MUST 能看任一学生。

#### Scenario: 本班学生可下钻
- **WHEN** 老师打开自己班某名学生的报告
- **THEN** 返回这名学生的弱项、掌握度、最近五次分数和待复习数

#### Scenario: 别班学生被拒
- **WHEN** 老师改网址里的学生编号，请求别班学生的报告
- **THEN** 返回 403，不返回任何数据

#### Scenario: 转出学生只有历史数字
- **WHEN** 学生转出原班后老师打开原班报告
- **THEN** 原班报告仍显示这名学生当时的考试数字，但不提供进入其报告的入口

#### Scenario: 转到同一位老师别的班也不给原班入口
- **WHEN** 学生从一班转到同一位老师带的三班，老师打开一班的报告
- **THEN** 一班报告仍显示这名学生当时的考试数字，但不提供报告入口；要从三班的报告进入

#### Scenario: 学生只看自己的
- **WHEN** 学生请求自己的报告
- **THEN** 只返回自己的数据
