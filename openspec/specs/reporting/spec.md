# reporting Specification

## Purpose

把已判分考试的逐题作答按知识点汇总成学生能看的弱项：固定错误率口径、样本门槛、前三排序，并区分「没有学习记录」与「暂时没有可统计的弱项」。

## Requirements

### Requirement: 错误率口径
错误率 MUST 等于错题数除以作答数。统计 MUST 只读已判分考试的逐题作答，每条逐题作答各算一次；同一道题答三次错两次时，分子 MUST 是 2，分母 MUST 是 3。一道题属于多个知识点时，MUST 在每个知识点的分子分母里各算一次。没有关联知识点的题、未判分记录、复习作答 MUST NOT 进入统计。本次练习模块尚未产生数据，练习记录 MUST NOT 被计入。

#### Scenario: 同一题多次作答各算一次
- **WHEN** 学生对一道题答了三次、错两次
- **THEN** 这道题所属知识点的作答数是 3，错题数是 2

#### Scenario: 一题多知识点各算一次
- **WHEN** 一道同时属于两个知识点的题答错了
- **THEN** 两个知识点各自的错题数都加 1，作答数也都加 1

#### Scenario: 未挂知识点的题不计
- **WHEN** 学生答错一道没有关联任何知识点的题
- **THEN** 任何知识点的错误率都不变

#### Scenario: 未判分记录不计
- **WHEN** 一条作答记录停在已交卷且分数为空
- **THEN** 它的逐题作答不进入任何知识点的分子或分母

#### Scenario: 复习作答不计
- **WHEN** 学生在复习里答错一道题
- **THEN** 任何知识点的错误率都不变

#### Scenario: 未作答按错计入
- **WHEN** 学生交白卷，卷内每道题都记了空答案并按错判
- **THEN** 这些题按错题计入各自知识点

### Requirement: 弱项前三与样本门槛
弱项排名 MUST 只计算作答数不少于 2 的知识点。排序 MUST 先按错误率降序，错误率相同时按作答数降序，再相同时按知识点 ID 升序；最多 MUST 返回 3 个。错误率 MUST 以百分比返回并保留一位小数；每条 MUST 含知识点 ID、名称、作答数、错题数和错误率。

#### Scenario: 样本不足不进排名
- **WHEN** 一个知识点只有 1 次作答且答错
- **THEN** 它的错误率虽是 100%，但不进入弱项排名

#### Scenario: 样本够但全对不占前三
- **WHEN** 一个知识点有 2 次作答且全对，另外三个知识点的错误率都高于 0
- **THEN** 这个知识点不进入前三

#### Scenario: 错误率相同按作答数排
- **WHEN** 两个知识点的错误率相同，一个作答 8 次、一个作答 4 次
- **THEN** 作答 8 次的排在前面

#### Scenario: 最多三个
- **WHEN** 五个知识点的作答数都达到门槛
- **THEN** 只返回错误率最高的三个

#### Scenario: 百分比一位小数
- **WHEN** 一个知识点作答 3 次、错 2 次
- **THEN** 错误率返回 66.7

### Requirement: 无数据状态
学生没有任何已判分的逐题作答时，弱项接口 MUST 返回 `has_data` 为 false 和空列表，页面 MUST 显示「还没有学习记录」，MUST NOT 显示掌握度 0 或分数 0。学生有已判分作答、但没有知识点达到样本门槛时，MUST 返回 `has_data` 为 true 和空列表，页面 MUST 显示「暂无可统计的弱项」，MUST NOT 显示「还没有学习记录」。

#### Scenario: 新学生没有学习记录
- **WHEN** 一个还没有考过试的学生请求弱项
- **THEN** 返回 has_data=false 和空列表

#### Scenario: 有作答但没挂知识点
- **WHEN** 学生考过试，但答过的题都没有关联知识点
- **THEN** 返回 has_data=true 和空列表，页面显示「暂无可统计的弱项」

#### Scenario: 有作答但样本不足
- **WHEN** 学生只做过一道题，且它关联的知识点作答数不到 2
- **THEN** 返回 has_data=true 和空列表，不把 100% 当成弱项

### Requirement: 弱项的可见范围
学生 MUST 只能读取自己的弱项。老师 MUST 返回 403 且不返回任何统计。管理员 MUST 能指定学生读取其弱项；未指定学生 MUST 返回 400；学生不存在 MUST 返回 404。

#### Scenario: 学生只看自己的
- **WHEN** 学生请求弱项
- **THEN** 只统计这名学生自己的作答

#### Scenario: 老师没有弱项入口
- **WHEN** 老师请求学生的弱项
- **THEN** 返回 403，不返回任何统计

#### Scenario: 管理员指定学生
- **WHEN** 管理员带学生 ID 请求弱项
- **THEN** 返回该学生的弱项

#### Scenario: 管理员不指定学生
- **WHEN** 管理员不带学生 ID 请求学生弱项
- **THEN** 返回 400，不返回统计

#### Scenario: 指定的学生不存在
- **WHEN** 管理员用一个不存在的学生 ID 请求弱项
- **THEN** 返回 404，不返回统计

### Requirement: 合并后重算
弱项 MUST 每次请求现算，MUST NOT 读缓存或存快照。知识点合并后再次请求，MUST 按合并后的目标知识点重新汇总；合并前的源知识点 MUST NOT 再出现在结果里。

#### Scenario: 合并两个知识点后重算
- **WHEN** 两个知识点各有一些作答，老师把它们合并成一个，然后学生刷新弱项
- **THEN** 两个知识点的作答数与错题数合并在目标知识点下，源知识点不再出现
