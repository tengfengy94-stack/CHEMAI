# review Specification

## Purpose

把考试产生的错题排进一条带时间的复习线：判分后自动入队、按固定间隔升级或归零、到期后由学生重新作答，并在第 5 级出队。复习作答复用考试的判分规则，但不改写考试数据。

## Requirements

### Requirement: 判分完成时错题自动入队
考试判分成功后，系统 MUST 为每道答错的题建立一条复习任务，初始为第 0 级，到期日为判分完成日的次日（按固定 UTC+8 业务日期）。同一学生同一道题 MUST 只有一条任务；已有任务 MUST 重置为第 0 级并按本次判分时间重排，MUST NOT 新增第二条。已出队的题再次答错 MUST 用原任务重新入队。判分失败或记录未判分时 MUST NOT 入队。入队 MUST 与判分在同一事务内完成；入队失败时整次判分 MUST 回滚到「已交卷 + 空分」。

#### Scenario: 判分后错题入队
- **WHEN** 学生的一次考试判分成功，其中一道题答错
- **THEN** 该学生这道题有一条第 0 级的复习任务，到期日为判分完成日的次日

#### Scenario: 未作答的题也入队
- **WHEN** 学生交卷时有一道题没答，判分按错算
- **THEN** 这道题同样进入复习队列，第 0 级，次日到期

#### Scenario: 同一题再考错只保留一条
- **WHEN** 学生在另一次考试里再次答错同一道题
- **THEN** 这道题仍只有一条复习任务，级别归零，到期日按后一次判分时间重排

#### Scenario: 已出队再考错重新入队
- **WHEN** 一道题已经复习到第 5 级出队，学生在新考试里又答错
- **THEN** 原任务回到第 0 级并重新出现在到期列表，不新增任务

#### Scenario: 判分失败不入队
- **WHEN** 学生交卷后判分失败，记录停在已交卷且分数为空
- **THEN** 不产生任何复习任务

#### Scenario: 入队失败整次判分回滚
- **WHEN** 判分成功但写复习任务时出错
- **THEN** 记录回滚为已交卷且分数为空，不留下半截任务，学生可以重试判分

### Requirement: 级别与间隔固定
复习任务 MUST 只有 0–5 级。间隔表 MUST 按「作答后的级别」取值：0 级 1 天（用于入队与答错归零）、1 级 3 天、2 级 7 天、3 级 14 天、4 级 30 天；5 级为出队。答对 MUST 升一级，下次到期 MUST 等于本次作答的 UTC+8 业务日期加上新级别的间隔；从第 4 级答对进入第 5 级时 MUST 出队，不再有到期日。答错 MUST 回到第 0 级，次日到期。级别 MUST 只由答对答错决定，时间流逝 MUST NOT 改变级别。

#### Scenario: 第 0 级答对到第 1 级
- **WHEN** 第 0 级的任务作答正确
- **THEN** 级别变为 1，下次到期是本次作答日 + 3 天

#### Scenario: 各级间隔按新级别取
- **WHEN** 第 1、2、3 级的任务分别作答正确
- **THEN** 下次到期分别是本次作答日 + 7 天、+ 14 天、+ 30 天

#### Scenario: 第 4 级答对出队
- **WHEN** 第 4 级的任务作答正确
- **THEN** 级别变为 5，任务出队，不再有下次到期日

#### Scenario: 答错回到第 0 级
- **WHEN** 第 3 级的任务作答错误
- **THEN** 级别变为 0，次日到期

#### Scenario: 第 0 级答错仍是第 0 级
- **WHEN** 第 0 级的任务作答错误
- **THEN** 级别保持 0，次日到期

#### Scenario: 逾期不降级
- **WHEN** 一条第 3 级的任务逾期五天，学生今天才打开复习列表
- **THEN** 级别仍是 3，到期日不变，只把任务排在列表最前

#### Scenario: 同一天答两次照常升级
- **WHEN** 学生今天把第 0 级任务答对，再次作答同一任务又答对
- **THEN** 两次都成功，级别依次变为 1 和 2

### Requirement: 到期列表
学生的到期列表 MUST 只包含自己级别 0–4、且到期日不晚于当前 UTC+8 业务日期的任务，按到期日升序排列，同一天按任务先后升序。逾期任务 MUST 正常返回并排在最前，读取时 MUST NOT 清零、降级或修改任务。列表条目 MUST 含题干、题型、选项、级别、到期日和上次答案，MUST NOT 含标准答案与解析。

#### Scenario: 今天到期出现
- **WHEN** 学生有一条到期日等于今天的任务
- **THEN** 它出现在到期列表里

#### Scenario: 未来任务不出现
- **WHEN** 学生有一条到期日在明天的任务
- **THEN** 它不出现在今天的到期列表里

#### Scenario: 逾期排最前
- **WHEN** 列表里有一条逾期五天的任务和一条今天到期的任务
- **THEN** 逾期的排在前面，两者的级别都不变

#### Scenario: 读取不修改任务
- **WHEN** 学生连续两次打开到期列表
- **THEN** 两次返回的级别和到期日完全相同

#### Scenario: 列表不提前泄露答案
- **WHEN** 学生请求到期列表
- **THEN** 条目里没有标准答案与解析

### Requirement: 复习作答判分
学生提交复习答案时，系统 MUST 使用与考试相同的答案比较规则判分，MUST NOT 让学生自评。只有任务所属学生 MUST 能作答；老师与管理员的作答请求 MUST 返回 403。任务不存在 MUST 返回 404；任务已到第 5 级 MUST 拒绝并返回 400。单题答案长度上限 MUST 与考试一致。判分成功后 MUST 按级别规则更新任务，并返回学生答案、标准答案、解析、本次对错、上次答案、新级别、下次到期日或出队标记。复习作答 MUST NOT 写入考试作答记录、改变考试分数或错题清单。

#### Scenario: 按考试规则判单选
- **WHEN** 标准答案是 A，学生在复习里提交「 A 」
- **THEN** 判对，与考试结果一致

#### Scenario: 按考试规则判多选
- **WHEN** 标准答案是 AC，学生在复习里提交「CA」
- **THEN** 判对；提交「A」则判错

#### Scenario: 按考试规则判填空
- **WHEN** 标准答案是 NaCl，学生在复习里提交全角加空格的「Ｎａ Ｃｌ」
- **THEN** 判对；提交「nacl」则判错

#### Scenario: 答对后升级
- **WHEN** 第 1 级的任务作答正确
- **THEN** 级别变为 2，下次到期是本次作答日 + 7 天

#### Scenario: 答错后归零
- **WHEN** 第 2 级的任务作答错误
- **THEN** 级别变为 0，次日到期

#### Scenario: 显示上次答案
- **WHEN** 学生第二次作答同一任务
- **THEN** 结果里包含第一次提交的答案

#### Scenario: 第一次没有上次答案
- **WHEN** 学生第一次作答一条新任务
- **THEN** 结果里的上次答案为空

#### Scenario: 已出队不能再答
- **WHEN** 学生请求作答一条第 5 级的任务
- **THEN** 返回 400，任务状态不变

#### Scenario: 复习不写考试记录
- **WHEN** 学生完成一次复习作答
- **THEN** 对应考试的分数、逐题对错和错题清单的最近答错时间都不变

#### Scenario: 不存在返回 404
- **WHEN** 学生请求作答一条不存在的任务
- **THEN** 返回 404，不返回业务数据

#### Scenario: 他人任务被拒
- **WHEN** 学生请求作答另一名学生的任务
- **THEN** 返回 403，不返回业务数据，不修改任务

#### Scenario: 老师和管理员不能代答
- **WHEN** 老师或管理员请求替学生作答一条复习任务
- **THEN** 返回 403，任务不变

### Requirement: 复习作答的并发
同一任务的两个作答请求同时到达时，系统 MUST 只允许一个成功并更新级别；后到的请求 MUST 返回 400，MUST NOT 再次升级或覆盖上次答案。顺序到达的两次作答 MUST 都成功，并按两次分别升降。

#### Scenario: 并发只有一个成功
- **WHEN** 同一任务的两个作答请求同时提交
- **THEN** 一个成功，另一个返回 400，级别只变化一次

#### Scenario: 顺序两次都成功
- **WHEN** 学生先提交一次、等结果返回后再提交一次
- **THEN** 两次都成功，级别按两次作答连续变化

### Requirement: 出队保留任务
第 5 级出队 MUST 只影响到期列表与作答入口。任务 MUST 保留，系统 MUST 仍能给出该学生这道题的当前级别、复习次数和最近一次答案。出队 MUST NOT 删除任务，也 MUST NOT 删除错题清单里的题。

#### Scenario: 出队后不在到期列表
- **WHEN** 一条任务升到第 5 级
- **THEN** 它不再出现在任何到期列表里

#### Scenario: 出队后仍可查询
- **WHEN** 学生请求全部复习任务
- **THEN** 已出队的任务仍在列表里，级别为 5，并带复习次数

#### Scenario: 出队不影响错题清单
- **WHEN** 一道题复习到第 5 级出队
- **THEN** 它仍然出现在该学生的错题清单里

### Requirement: 复习任务可见范围
学生 MUST 只能读取自己的复习任务与到期列表；管理员 MUST 能读取全部学生的任务并带学生标识；老师 MUST 返回 403 且不返回任何任务数据。读取不存在的任务 MUST 返回 404。

#### Scenario: 学生只看自己的
- **WHEN** 学生请求复习任务列表
- **THEN** 只返回自己的任务

#### Scenario: 管理员看全部
- **WHEN** 管理员请求复习任务列表
- **THEN** 返回全部学生的任务，每条带学生 ID 与姓名

#### Scenario: 老师没有复习入口
- **WHEN** 老师请求复习任务列表
- **THEN** 返回 403，不返回任何任务数据

#### Scenario: 不存在返回 404
- **WHEN** 请求一条不存在的复习任务
- **THEN** 返回 404，不返回业务数据
