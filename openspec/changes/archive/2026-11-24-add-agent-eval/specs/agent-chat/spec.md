# Spec Delta

## MODIFIED Requirements

### Requirement: 对话按线程存档

服务端 MUST 按当前登录用户划分独立对话线程：学生按学生编号一人一条，老师按账号与当前班级一条。同一线程的上下文 MUST 只属于该身份；两个学生、两个班级、学生与老师之间 MUST NOT 串线。生产模式下线程编号 MUST 由服务端推导，MUST NOT 接受客户端或模型指定。评测模式（`CHEMAI_EVAL_MODE`）下，客户端 MAY 提供一个隔离后缀，服务端 MUST 把它拼接到当前身份之后；该后缀 MUST NOT 让请求越过当前身份。系统 MUST 提供历史接口，只返回当前身份当前线程的消息。

#### Scenario: 刷新后恢复当前线程
- **WHEN** 学生发完一句话后刷新或重新打开对话页
- **THEN** 页面通过历史接口读回同一线程刚才的用户消息与助教回答

#### Scenario: 两个学生互不串线
- **WHEN** 两个学生同时使用对话页
- **THEN** 各自只看到自己的线程，回答不引用另一个学生的内容

#### Scenario: 老师按班级分线
- **WHEN** 老师从一班切到二班再提问
- **THEN** 老师看到的是一班线程之外的另一条二班线程，两班上下文不混

#### Scenario: 客户端不能指定线程
- **WHEN** 客户端在请求里放入一个线程编号或学生编号
- **THEN** 服务端忽略该值，仍按当前登录身份选择线程

#### Scenario: 评测模式隔离对话线
- **WHEN** 评测模式开启，两条用例携带不同的隔离后缀
- **THEN** 两条用例各自拥有独立线程，互相看不到对方的消息与摘要
