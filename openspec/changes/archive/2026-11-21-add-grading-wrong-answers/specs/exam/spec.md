# Spec Delta

## ADDED Requirements

### Requirement: 错题清单按学生和题去重

判分完成后，错题清单 MUST 以「学生 + 题目」为单位去重：同一名学生的同一道题 MUST 只出现一条，显示该题最近一次答错时的学生答案、来源和答错时间。同一道题再次答错 MUST 更新这条记录，MUST NOT 新增一条；答对 MUST NOT 把题从错题清单移走。

#### Scenario: 同一道题错三次只留一条

- **WHEN** 学生在一道题上先后答错三次
- **THEN** 错题清单只有这一道题的一条记录，学生答案是最近一次答错的答案

#### Scenario: 答对不移出错题清单

- **WHEN** 学生错过一道题，后来在同一道题上答对
- **THEN** 这道题仍在错题清单里，最近一次答错的答案和时间不变

#### Scenario: 不同学生的同一道题不合并

- **WHEN** 两名学生都在同一道题上答错
- **THEN** 错题清单里有两名学生的各一条记录，不互相覆盖

#### Scenario: 最近答错排前面

- **WHEN** 学生的错题清单里有多个题目，最近一次答错的时间不同
- **THEN** 清单按最近一次答错时间倒序排列

### Requirement: 错题条目字段完整

每条错题 MUST 包含题干、选项（选择题）、学生的答案、标准答案、解析、来源和最近一次答错时间；考试来源 MUST 额外带卷子标题；管理员读取时 MUST 额外带学生 ID 与姓名，用于区分不同学生的记录。未作答的题 MUST 按空答案记为错题。

#### Scenario: 选择题错题字段

- **WHEN** 学生在一道选择题上答错
- **THEN** 错题条目含题干、选项、学生答案、标准答案、解析、来源和卷子标题

#### Scenario: 未作答的题进入错题

- **WHEN** 学生交卷时有一道题没答，判分按错算
- **THEN** 这道题出现在错题清单里，学生答案为空

### Requirement: 错题来源标记

考试判分产生的错题 MUST 标记来源为 `exam`，并 MUST 带上对应卷子标题。

#### Scenario: 考试错题来源

- **WHEN** 学生查看由考试判分产生的错题
- **THEN** 每条来源为 `exam`，并带对应卷子标题

### Requirement: 只有已判分记录产生错题

错题 MUST 只来自已判分且逐题对错已写入的记录。已交卷但分数为空的记录 MUST NOT 产生错题；判分失败重试成功后，错题 MUST 正常出现。

#### Scenario: 判分失败没有错题

- **WHEN** 学生交卷后判分失败，记录停在已交卷且分数为空
- **THEN** 错题清单不增加任何条目

#### Scenario: 重试成功产生错题

- **WHEN** 学生对判分失败的记录重试并判分成功
- **THEN** 答错的题出现在错题清单里

#### Scenario: 零分也有错题

- **WHEN** 学生交白卷并判分完成，分数为 0.0
- **THEN** 卷内每道题都出现在错题清单里

### Requirement: 错题清单的可见范围

错题的可见范围 MUST 与结果详情一致：学生 MUST 只能读取自己的错题；管理员 MUST 可以读取全部错题；其他角色 MUST 返回 403，MUST NOT 返回任何错题数据。

#### Scenario: 学生只看自己的错题

- **WHEN** 学生请求错题清单
- **THEN** 只返回该学生自己答错的题

#### Scenario: 管理员可看全部

- **WHEN** 管理员请求错题清单
- **THEN** 返回全部学生的错题，每条带学生 ID 与姓名

#### Scenario: 老师没有错题入口

- **WHEN** 老师请求错题清单
- **THEN** 返回 403，不返回任何数据

### Requirement: 已判分结果提供看错题动作

已判分记录的详情 MUST 同时提供「查看结果」和「看错题」两个动作；「看错题」MUST 打开错题清单并展示按题去重后的全部错题，MUST NOT 只限当前这份卷子。未判分或判分失败的记录 MUST NOT 提供看错题动作。

#### Scenario: 已判分记录有两个动作

- **WHEN** 学生打开一条已判分记录
- **THEN** 页面提供查看结果和看错题两个动作

#### Scenario: 看错题展示全部错题

- **WHEN** 学生从某次结果点看错题
- **THEN** 错题清单包含该学生所有已判分考试里的错题，而不只是当前卷子的错题

#### Scenario: 判分没完成没有看错题

- **WHEN** 记录停在已交卷且分数为空
- **THEN** 结果态不提供看错题动作，错题清单也没有这次作答

#### Scenario: 错题为空有明确提示

- **WHEN** 学生没有任何错题
- **THEN** 看错题动作显示空状态提示，不显示空白列表
