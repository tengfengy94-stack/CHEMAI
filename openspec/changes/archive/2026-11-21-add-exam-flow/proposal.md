# Proposal

## Why

前四章把题目、账号和权限做完了，但题目通过审核之后没有出口：老师不能组卷，学生看不到卷子，`papers_using_question` 仍是恒返回 0 的占位实现。这一章把"题 → 卷 → 发布 → 作答 → 判分"的主链路接通，题库才真正变成可用于周测的资产，而不是只能录入和浏览的表格。

## What Changes

- 新增**卷子**对象，只有 `草稿` 和 `已发布` 两种状态。组卷只接受当前老师自己的**已通过**题；同一道题在一份卷子里只出现一次；题目顺序就是加入顺序；空卷不能发布；发布与加题、减题互斥，发布后卷子内容只读，但可以再发给别的班。
- 新增**按班发布**：发布时给班内每个学生各建一条作答记录，并记下发布时的班级快照；重复发布给同一个班跳过已有记录、只补缺的学生；班级没有学生时拒绝发布；已发布卷子可以再发给另一个班；转出学生的记录保留，已在其他班有该卷记录的学生不再重复建。
- 新增**作答记录**对象，四态单向流转：`待作答 → 作答中 → 已交卷 → 已判分`。重复点"开始"按继续处理；交卷只收一次；判分在交卷的同一次请求里同步完成；判分失败时停在 `已交卷` 且分数为空，重试判分走独立入口，只重判、不重收答案；判分进行中的重复交卷一律 400，不会滑进重试。
- 新增学生作答接口：作答过程中只下发题干、题型和选项，不下发标准答案与解析；判分完成后结果页可回看整份卷子（题干、自己的答案、标准答案、解析、对错）。
- **非法状态转移一律返回 400**，并给出中文原因，不允许静默通过。设计明确允许的幂等操作（同一道题重复加入、同一份卷子重复发布给同一个班、`作答中` 再点开始）不属于非法转移，仍返回 200 且不报错。
- 新增两个页面：老师**组卷/发布页** `/teacher/exams`，学生**考试页** `/student/exams`（列表、作答、结果三态）。
- 用真实的卷子查询替换 `backend/app/routes.py` 里的 `papers_using_question` 占位实现，让题目删除检查从这一章起真正生效。

**不在本次范围**：班级报告/成绩统计页、错题本页面、复习与练习、撤回发布、重考、限时与倒计时、拖动排序、主观题与多空填空。逐题作答和判分结果会为后续错题与报告提供数据，但本次不开放对应页面。

## Capabilities

### New Capabilities

- `exam`: 卷子的组卷与发布、作答记录的创建与四态流转、同步判分与判分失败重试、作答与结果查看时的答案可见性，以及非法状态转移的拒绝语义。

### Modified Capabilities

无。现有 `question-bank` 已规定"被卷子用过的题不能删"，本次只是把该规则需要的卷子表接上，不改变其需求；`access-control` 的三条规则直接适用于新增接口，无需改需求。

## Impact

- **后端**：`backend/app/models.py` 新增卷子、卷子题目、作答记录、逐题作答四张表；新增 Alembic 迁移 `0003_exam.py`；`backend/app/routes.py` 新增组卷、发布、作答、交卷与重试判分接口并替换 `papers_using_question`；`backend/app/schemas.py` 新增入参校验；`backend/app/answers.py` 增加与建题同源的判分比较函数；新增题库到考试的测试。
- **前端**：`frontend/src/App.jsx` 增加 `/teacher/exams` 路由；新增 `pages/teacher/Exams.jsx`；把 `pages/student/Exams.jsx` 从占位页改成列表/作答/结果三态；`api.js` 增加考试接口；`constants.js` 增加卷子与作答状态标签。
- **数据**：开发库 `chemai.db` 需要执行新迁移；测试临时库继续由 Alembic 建到 head。已有题目数据不受影响。
- **权限**：复用现有 `get_current_user`、`require_owner`、`require_own_class`。老师只能操作自己建的卷子、只能发布给自己带的班；学生只能看自己的作答记录，开始与交卷只能是记录所属学生；管理员可读全部卷子和作答记录、可操作卷子，但不能代替学生开始或交卷。
- **接口契约**：继续使用 `{success, data, error}` 信封。权限不足返回 403，对象不存在返回 404，入参格式错误返回 422；**状态机非法转移与业务规则拒绝统一返回 400**（例如未开始就交卷、重复交卷、已判分再交、空卷发布、空班发布）。格式错误优先 422，不进入状态机判定。
