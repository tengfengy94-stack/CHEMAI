## 4. 作答与判分接口

- [x] 4.1 实现 `GET /api/attempts` 与 `GET /api/attempts/{id}`：学生只看自己的记录，管理员可读全部但不能代替学生操作；详情按状态返回字段，`pending` 不下发题目，`in_progress/submitted` 不含标准答案与解析，`submitted` 带 `grading_in_progress`，`graded` 才含答案、解析、对错与分数；验证：API 测试覆盖列表范围、他人记录 403、各状态字段差异、`grading_in_progress` 与租约一致。
- [x] 4.2 实现 `POST /api/attempts/{id}/start`：只允许记录所属学生触发；`pending → in_progress`；`in_progress` 再点返回 200 按继续处理且不覆盖 `started_at`；`submitted/graded` 返回 400；他人或管理员触发返回 403；验证：API 测试覆盖五条分支，断言状态、时间字段与权限。
- [x] 4.3 实现 `POST /api/attempts/{id}/submit` 的收答案部分：只接受 `in_progress`；校验 `question_id` 属于本卷且不重复，非法请求 400 且不落库；为卷内每道题写一条逐题作答，未答写空串；用条件更新 `in_progress → submitted` 并写 `submitted_at`、`grading_started_at`；`submitted`/`graded` 一律返回 400，不允许从交卷入口走重试；验证：API 测试覆盖未开始交卷 400、未答记空、白卷、已交卷重复交 400、已判分重复交 400、慢判分测试中第二个交卷返回 400 且答案不被覆盖。
- [x] 4.4 实现 `POST /api/attempts/{id}/retry-grading`：只接受 `submitted + score=NULL`；用 `grading_started_at` 租约抢占，抢不到返回 400「判分正在进行」；抢到后只重跑判分，不读请求体答案；判分事务成功写 `is_correct/score/graded` 并清空租约，失败保留答案与空分并清理租约，租约过期后可再次重试；验证：API 测试覆盖重试成功、判分失败、两个并发重试只有一个 200、租约过期后可重试、已判分重试 400、答案不被覆盖。
- [x] 4.5 统一考试接口的错误与数据一致性：非法状态转移与业务规则返回 400，权限 403，不存在 404，字段格式错误优先 422；`score` 为 `None` 时序列化为 `null`，0 分序列化为 `0.0`；未判分时逐题对错为空，判分后全部写入；验证：测试逐条断言状态码、`error` 文案、空分与零分可区分、无半截数据。
