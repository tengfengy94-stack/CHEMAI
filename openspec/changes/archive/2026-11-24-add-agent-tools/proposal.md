# Proposal

## Why

第 11 章只打通了单轮流式对话：没有工具、没有历史、没有场景。设计 04 §4.3–§4.4 要求助教先查真实数据再回答，十个工具按角色裁剪，学生画像每次现查，对话按学生分线存档。没有这一章，"你氧化还原错了三次"只能靠模型编，班级弱项也只能靠老师自己翻报告。

这一章把 Agent 从"会说话的模型"补成"会查库的助教"，并把循环、记忆、权限和教师问答一起落地。

## What Changes

- 引入 LangChain v1 `create_agent` + LangGraph + SQLite checkpointer，替换第 11 章手写的单轮模型调用；循环由框架负责，不自己写状态机。
- 新增十个工具，九个只读、一个写（加复习）：
  - 学生可用九个：搜题、找知识点、看学生画像、看知识地图、讲错题、看到期复习、布置练习、加复习、看考试结果。
  - 老师只用五个只读工具：搜题、找知识点、看知识地图、看考试结果、看班级概况。
  - 工具身份从运行时上下文读取，签名里不出现学生编号或班级编号；工具内部调用已有服务函数，不发 HTTP 调自己的接口。
- 对话按线程存档：
  - 学生一人一条线；老师按"账号 + 当前班级"一条线。
  - 新增历史接口，刷新或重新打开对话页能读回当前线程；保留最近 20 条，超过 30 条压缩成摘要。
- 新增场景人设：练习页、错题页、对话页各带场景进来，服务端按场景换提示词，不另起接口或智能体。
- 循环上限 8 次模型调用；到上限强制收尾，给出已有信息。
- 流里新增 `tool` 事件，显示"正在查你的学习情况"这类提示，不显示参数；`text` 仍逐字输出，`end` 仍最后发。
- 老师对话页增加班级选择：老师带多个班时必须先选班，服务端校验归属；老师问本班学生考试结果时按姓名在本班内解析，不接受学生编号。
- 前端练习页支持"按对话带来的题单依次出题"；错题页、练习页增加"问一句"入口。
- 依赖新增 `langchain`、`langgraph`、`langgraph-checkpoint-sqlite`，替代第 11 章"不引入 LangGraph"的取舍。

**明确不做**：

- 不做 AI 出题、AI 判分、改分、改答案。
- 不做向量检索、跨学生共享记忆、从历史对话总结学生性格。
- 不做老师专用智能体或第二套人设；老师和学生共用同一个接口与同一个页面，只按角色裁剪工具。
- 不做外部工具协议、语音、图片、主动推送。
- 不放开学生自己的作答接口给老师；老师看本班成绩走新的 Agent 工具路径。
- 不把知识点管理接口开放给学生；学生只能通过 Agent 看到单个知识点的名称与上下级名称。

## Capabilities

### New Capabilities

- `agent-tools`: 助教的工具循环——十个工具的行为、按角色可用范围、运行时身份注入、只返回当前身份可见的数据、工具失败不抛异常、8 次模型调用上限、唯一写操作只写当前学生的复习任务。

### Modified Capabilities

- `agent-chat`: 第 11 章的"无工具、无历史"要求改为带工具事件、按线程存档、历史读取、场景人设和班级上下文；同一接口同时服务学生与老师。
- `exam`: 允许老师通过 Agent 工具读取本班学生已判分考试的摘要（总分 + 每题对错），原有作答接口仍只允许学生本人与管理员。
- `knowledge-map`: 允许学生通过 Agent 工具读取单个知识点的名称、别名、上级与下级名称；知识点管理接口对学生仍返回 403，完整树仍只给老师与管理员。
- `practice`: 练习页支持按对话带来的题单依次出题，题单离开或答完即失效；在学生真正作答前不写练习记录。
- `review`: 允许手动为当前学生加入一条复习任务（第 0 级、明天到期、已有任务只挪到期日），不改变考试判分自动入队的原有规则。

## Impact

- 后端：新增 Agent 图、工具模块、线程与历史读取、老师班级上下文；`agent.py` 的单轮模型调用改为图调用；`agent_routes.py` 增加 `tool` 事件、历史接口、`class_id` 校验；`requirements.txt` 增加 LangChain / LangGraph / SQLite checkpointer；`create_app` 增加图与 checkpointer 的启动装配。
- 前端：`Chat.jsx` 增加历史恢复、工具提示、老师班级选择器、场景参数；练习页增加题单模式；练习页与错题页增加"问一句"入口；去掉"刷新即清空"的文案。
- 数据：新增 LangGraph checkpointer 表（框架管理，不进 Alembic）；业务表无结构变更。
- 接口：`POST /api/chat/stream` 请求增加 `class_id`（老师）与 `scene`；新增 `GET /api/chat/history`；SSE 增加 `tool` 事件。
- 测试：新增工具选择、线程隔离、历史恢复、8 次上限、老师本班权限、知识点学生只读范围、手动加复习、题单练习的测试；现有测试保持全绿。三十条评测留到评测章，本章只保证线程隔离可用。
