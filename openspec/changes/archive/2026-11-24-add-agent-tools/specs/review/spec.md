# Spec Delta

## ADDED Requirements

### Requirement: 手动加入复习任务

学生 MUST 能通过 Agent 工具为当前学生把一道题加入复习队列。没有任务时 MUST 建一条第 0 级、明天到期的任务；已有任务时 MUST NOT 新增第二条，级别 0–4 MUST 保留原级别并把到期日提前到明天，级别 5 MUST 回到第 0 级并按明天到期重新入队。题 MUST 存在且已通过审核；MUST NOT 修改分数、答案或其他学生的任务。

#### Scenario: 新加一道题

- **WHEN** 学生对一道没有复习任务的题说"帮我记一下，过几天再做"
- **THEN** 系统建一条第 0 级、明天到期的复习任务

#### Scenario: 已有任务只提前到期日

- **WHEN** 学生对一道已有第 2 级任务的题说"帮我记一下"
- **THEN** 原任务仍是第 2 级，只把到期日提前到明天，任务条数不变

#### Scenario: 已出队任务重新入队

- **WHEN** 学生对一道已经第 5 级出队的题说"帮我记一下"
- **THEN** 原任务回到第 0 级，明天到期，重新出现在到期列表

#### Scenario: 不能给别的学生加

- **WHEN** 请求试图给另一个学生加复习任务
- **THEN** 拒绝，不写任何数据

#### Scenario: 题目不可用

- **WHEN** 题目不存在或未通过审核
- **THEN** 拒绝，不建任务，返回中文原因
