# Spec Delta

## Purpose

规定助教可调用的十个工具及其边界：按角色裁剪工具清单、身份从运行时注入、只读为主、唯一写操作只写当前学生的复习任务，并约束工具失败与返回长度。

## ADDED Requirements

### Requirement: 工具循环与调用上限

助教 MUST 在一个循环里完成"模型判断是否调用工具 → 工具返回结果 → 模型继续回答"；每次用户请求 MUST 最多进行 8 次模型调用。达到上限时 MUST 停止继续调用工具，保留已经查到的结果并给出收尾回答，MUST NOT 让学生看到无限等待或原始报错。

#### Scenario: 先查后答

- **WHEN** 学生问"我氧化还原这块是不是不太行"
- **THEN** 助教先调用看学生画像，拿到弱项后再组织回答

#### Scenario: 第八次调用后收尾

- **WHEN** 模型已经进行了 8 次模型调用仍想继续调用工具
- **THEN** 系统停止循环，用已有结果给出中文收尾回答，不再发起第九次调用

#### Scenario: 不需要工具时直接回答

- **WHEN** 学生问"什么是氧化还原"这类通用知识
- **THEN** 助教可以直接回答，不强制调用工具，并说明这是通用解释而不是学生卷子上的内容

### Requirement: 工具身份与权限从运行时注入

工具 MUST 从服务端运行时上下文读取当前用户、角色与班级；工具参数 MUST NOT 包含学生编号、用户编号或班级编号。模型传入身份类参数时 MUST 被忽略或拒绝，工具 MUST NOT 据此扩大查询范围。学生工具 MUST 只返回当前学生自己的数据；老师工具 MUST 只返回当前班级的数据。

#### Scenario: 学生问别人的成绩

- **WHEN** 学生问"张三考了多少分"
- **THEN** 助教拒绝，不透露这个名字是否存在，也不返回任何他人数据

#### Scenario: 老师问别的班

- **WHEN** 老师问自己未带的另一个班的情况
- **THEN** 助教拒绝，只返回当前班级范围内的数据

#### Scenario: 模型试图传学生编号

- **WHEN** 模型在工具参数里放入一个学生编号或用户编号
- **THEN** 工具不接受该参数，仍按运行时身份查询，不返回第二个学生的数据

### Requirement: 角色工具清单

学生 MUST 可用九个工具：搜题、找知识点、看学生画像、看知识地图、讲错题、看到期复习、布置练习、加复习、看考试结果。老师 MUST 只用五个只读工具：搜题、找知识点、看知识地图、看考试结果、看班级概况。老师 MUST NOT 使用看学生画像、讲错题、看到期复习、布置练习、加复习。管理员 MUST 不获得任何业务工具，对话只保留通用回答。系统 MUST NOT 把某个角色不可用的工具暴露给模型。

#### Scenario: 学生不能用班级工具

- **WHEN** 学生问"我们班哪块最弱"
- **THEN** 学生工具清单里没有班级概况，助教拒绝并引导学生看自己的报告

#### Scenario: 老师不能用学生画像

- **WHEN** 老师问"我最近学得怎么样"
- **THEN** 老师工具清单里没有学生画像，助教按老师身份说明只能查班级层面的数据

#### Scenario: 老师只读

- **WHEN** 老师要求给某个学生加一条复习任务
- **THEN** 老师工具清单里没有加复习，助教拒绝，不写任何业务数据

#### Scenario: 管理员没有业务工具

- **WHEN** 管理员打开对话页提问
- **THEN** 管理员工具清单为空，只得到通用回答，不返回任何学生或班级数据

### Requirement: 知识类工具

搜题 MUST 只在已通过的题里按知识点、难度、数量筛选，默认 5 道、最多 20 道，返回题干、题型、难度，MUST NOT 返回答案与解析。找知识点 MUST 按名称和别名匹配并返回最接近的一个；匹配不到 MUST 说匹配不到，MUST NOT 猜一个最近的硬塞。看知识地图 MUST 只返回目标知识点的上级与下级名称，MUST NOT 返回整棵树。

#### Scenario: 搜题不带答案

- **WHEN** 学生要求练"氧化还原"的题
- **THEN** 助教返回最多 5 道已通过题的题号、题干、题型和难度，不返回答案与解析

#### Scenario: 知识点匹配不到

- **WHEN** 学生说一个库里没有的知识点名称
- **THEN** 助教说明库里没有这个点，不编造一个解释或强行匹配

#### Scenario: 知识地图只给上下级

- **WHEN** 学生问"学这个之前要先会什么"
- **THEN** 助教只返回该知识点的上级和下级名称，不返回完整树或题目列表

### Requirement: 学生画像与到期复习

看学生画像 MUST 每次现查当前学生的弱项前三、最近五次分数与待复习数，MUST NOT 读取对话历史里的旧结论。看到期复习 MUST 只返回当前学生级别 0–4 且到期日不晚于今天的任务，逾期任务排在最前，并 MUST 返回剩余条数。

#### Scenario: 画像每次现查

- **WHEN** 学生刚做完一道练习题，再问"我哪块弱"
- **THEN** 助教按最新练习记录重新计算弱项，不复用上一轮对话里的旧排名

#### Scenario: 到期列表只含到期任务

- **WHEN** 学生问"今天要复习什么"
- **THEN** 只返回今天及以前到期、级别 0–4 的任务，逾期任务排在最前，未来到期和已出队的任务不出现

#### Scenario: 待复习数

- **WHEN** 学生问"还有多少要复习"
- **THEN** 助教返回当前学生到期任务条数，并列出前几条任务

### Requirement: 讲错题与看考试结果

讲错题 MUST 读取当前学生对这道题的最近一次错误答案、题干、选项、标准答案与解析，并给出错因、正确思路和一道同类题；学生没答错过的题 MUST NOT 讲错。考试进行中 MUST 拒绝给答案。看考试结果 MUST 只返回总分与每题对错，MUST NOT 返回他人记录；未判分记录 MUST 说没有结果。老师路径 MUST 只查当前班级学生。

#### Scenario: 讲一道错题

- **WHEN** 学生问"我选 A 为什么不对"
- **THEN** 助教返回错因、正确思路和一道同类题，并给出同类题题号

#### Scenario: 没答错过的题

- **WHEN** 学生问一道自己没有答错过的题为什么错
- **THEN** 助教说明没有这道题的错题记录，不编造错误答案

#### Scenario: 考试进行中问答案

- **WHEN** 学生有一条作答中的记录，并问某道题选哪个
- **THEN** 助教拒绝给答案，说明考完可以一起看

#### Scenario: 未判分没有结果

- **WHEN** 学生问一条已交卷但还没判分的考试结果
- **THEN** 助教说明判分还没完成，不返回 0 分或猜测分数

### Requirement: 布置练习与加复习

布置练习 MUST 按弱项排名与当前难度选一组题，返回题号、题干、难度，默认 5 道；MUST NOT 写练习记录，题单 MUST NOT 长期保存。加复习 MUST 为当前学生建一条第 0 级、明天到期的任务；已有任务 MUST 不重复建，级别 0–4 MUST 保留原级别并把到期日提前到明天，级别 5 MUST 回到第 0 级并按明天到期重新入队。除加复习外，工具 MUST NOT 写任何业务数据。

#### Scenario: 布置练习不写记录

- **WHEN** 学生说"给我出几道题练"
- **THEN** 助教返回一组题，学生真正作答前不产生任何练习记录

#### Scenario: 新加一条复习

- **WHEN** 学生对一道没有复习任务的题说"这道题帮我记一下"
- **THEN** 系统建一条第 0 级、明天到期的任务

#### Scenario: 已有任务只提前到期日

- **WHEN** 学生对一道已有第 2 级复习任务的题说"过几天再做"
- **THEN** 原任务仍是第 2 级，只把到期日提前到明天，不新增第二条

#### Scenario: 已出队任务重新入队

- **WHEN** 学生对一道已经第 5 级出队的题说"这道题帮我记一下"
- **THEN** 原任务回到第 0 级，明天到期，重新出现在到期列表

#### Scenario: 不能给别的学生加复习

- **WHEN** 请求试图给另一个学生加复习任务
- **THEN** 拒绝，不写任何数据

### Requirement: 看班级概况

看班级概况 MUST 只返回当前老师所带班级的知识点错误率分布与学生人数，MUST NOT 返回其他班级、单个学生成绩或排名。班级 MUST 由运行时上下文确定，MUST NOT 由模型参数指定。

#### Scenario: 老师看本班弱项

- **WHEN** 老师问"我们班哪块最弱"
- **THEN** 助教返回当前班级的知识点错误率分布和学生人数

#### Scenario: 学生不能用班级概况

- **WHEN** 学生问"我们班哪块最弱"
- **THEN** 助教拒绝，不返回任何班级统计

#### Scenario: 不返回排名

- **WHEN** 老师问"班里谁考得最差"
- **THEN** 助教不返回学生排名或单个学生成绩，只给班级层面的分布

### Requirement: 工具失败与返回长度

工具查不到 MUST 返回"没找到"类中文结果，参数不合法 MUST 返回"参数不合法"，超时或内部错误 MUST 当作没查到处理；工具 MUST NOT 抛异常中断对话。列表类返回 MUST 默认 5 条、最多 20 条，并 MUST 在还有更多时告诉模型剩余条数；MUST NOT 返回整张表。

#### Scenario: 工具查不到

- **WHEN** 工具没有查到对应的题目或知识点
- **THEN** 返回中文"没找到"，对话继续，不显示报错页面

#### Scenario: 参数不合法

- **WHEN** 工具收到的难度不在 1、2、3 里
- **THEN** 返回中文"参数不合法"，不抛异常，不查库

#### Scenario: 工具超时

- **WHEN** 工具查询超时或内部出错
- **THEN** 当作这一项没查到处理，助教说明这一项没查到，不打断整轮对话

#### Scenario: 列表截断

- **WHEN** 符合条件的题超过 20 道
- **THEN** 只返回前 20 道，并告诉模型还有多少道没有返回
