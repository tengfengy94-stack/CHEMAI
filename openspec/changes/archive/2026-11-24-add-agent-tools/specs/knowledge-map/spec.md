# Spec Delta

## MODIFIED Requirements

### Requirement: 知识点树的读取

老师与管理员 MUST 能读取完整知识点树，每个节点 MUST 含名称、别名、上级和直接关联的题目数。学生 MUST 返回 403 且不返回知识点数据。读取 MUST NOT 修改任何节点或关联。学生通过 Agent 工具读取单个知识点的名称、别名、上级与下级名称属于唯一例外，按「学生通过 Agent 读取单个知识点」执行。

#### Scenario: 老师读取整棵树
- **WHEN** 老师请求知识点树
- **THEN** 返回两层结构和每个节点的名称、别名、题目数

#### Scenario: 学生无权读取
- **WHEN** 学生请求知识点树
- **THEN** 返回 403，不返回任何知识点数据

## ADDED Requirements

### Requirement: 学生通过 Agent 读取单个知识点

学生 MUST 能通过 Agent 工具读取一个知识点的名称、别名、上级名称和下级名称，用于理解知识点归属和前置关系。返回 MUST NOT 包含完整树、题目数、题目列表或其他知识点的数据。知识点匹配不到时 MUST 说明匹配不到，MUST NOT 猜一个最近的节点。

#### Scenario: 学生问前置知识

- **WHEN** 学生问"学氧化还原之前要先会什么"
- **THEN** 助教返回氧化还原的上级名称和下级名称，不返回整棵树

#### Scenario: 学生问知识点归属

- **WHEN** 学生问"氧化剂属于哪一块"
- **THEN** 助教返回氧化剂所属的上级知识点名称

#### Scenario: 学生不能拉整棵树

- **WHEN** 学生要求列出全部知识点
- **THEN** 助教拒绝，只按单个知识点回答

#### Scenario: 匹配不到不硬猜

- **WHEN** 学生说的知识点在库里不存在
- **THEN** 助教说明库里没有这个点，不返回一个相近节点冒充
