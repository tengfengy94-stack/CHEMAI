# Spec Delta

## ADDED Requirements

### Requirement: 按对话题单练习

练习页 MUST 支持从对话带来的题单进入：按题单顺序依次出题，答完或离开页面后题单失效，MUST NOT 长期保存。题单模式 MUST NOT 改变默认按弱项出题的行为；MUST NOT 在学生真正作答前写练习记录；题单里的题 MUST 是已通过的题。

#### Scenario: 从对话去练

- **WHEN** 学生在对话里点"去练"并带到练习页
- **THEN** 练习页按对话给的那组题依次出题，而不是重新按弱项选题

#### Scenario: 按题单顺序出题

- **WHEN** 题单里有 5 道题，学生答完第一道
- **THEN** 下一道按题单顺序出现

#### Scenario: 作答才写记录

- **WHEN** 学生只是打开题单但没有提交任何答案
- **THEN** 不产生练习记录

#### Scenario: 离开后题单失效

- **WHEN** 学生离开练习页再重新打开默认练习
- **THEN** 不再使用上一次对话的题单，回到按弱项出题

#### Scenario: 题单里的题都可用

- **WHEN** 题单里的题在出题时已被删除或未通过审核
- **THEN** 跳过该题或返回空态，不把不可用的题发给学生
