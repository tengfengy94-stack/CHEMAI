# Spec Delta

## MODIFIED Requirements

### Requirement: 考试数据的归属范围

老师 MUST 只能看到和操作自己创建的卷子，MUST 只能发布给自己带的班。学生 MUST 只能看到自己的作答记录，MUST NOT 读取或修改他人的记录；开始与交卷 MUST 只能由记录所属学生发起。管理员 MUST 可以读取全部卷子与作答记录，MUST 可以操作卷子，但 MUST NOT 代替学生开始或交卷。访问他人对象 MUST 返回 403，对象不存在 MUST 返回 404，且 MUST NOT 返回任何业务数据。老师通过 Agent 工具读取本班学生已判分考试摘要属于唯一例外，按「老师通过 Agent 读取本班考试摘要」执行。

#### Scenario: 老师操作他人卷子被拒
- **WHEN** 老师请求修改另一位老师创建的卷子
- **THEN** 返回 403，不修改任何数据

#### Scenario: 老师发布到别班被拒
- **WHEN** 老师把卷子发布给自己未带的班
- **THEN** 返回 403，不创建作答记录

#### Scenario: 学生看他人记录被拒
- **WHEN** 学生请求读取另一名学生的作答记录
- **THEN** 返回 403，不返回任何数据

#### Scenario: 管理员可操作卷子
- **WHEN** 管理员请求操作任一老师的卷子
- **THEN** 允许

#### Scenario: 管理员不能代替学生交卷
- **WHEN** 管理员请求对某条作答记录执行开始或交卷
- **THEN** 返回 403，状态不变

#### Scenario: 对象不存在返回 404
- **WHEN** 请求的卷子或作答记录不存在
- **THEN** 返回 404，不返回业务数据

## ADDED Requirements

### Requirement: 老师通过 Agent 读取本班考试摘要

老师 MUST 能通过 Agent 工具读取本班学生已判分考试的摘要：总分与每题对错。查询 MUST 限定当前班级，MUST 按发布时班级快照匹配，MUST 只返回已判分记录；MUST NOT 返回标准答案、解析、其他班数据或其他学生数据。工具参数 MUST NOT 包含学生编号；学生 MUST 在当前班级内按姓名解析，同名无法唯一确定时 MUST 要求补充信息，MUST NOT 猜一个。

#### Scenario: 老师查本班学生

- **WHEN** 老师在自己的班级上下文里问某个本班学生上次考试考了多少
- **THEN** 返回该学生这次已判分考试的总分和每题对错

#### Scenario: 别班学生查不到

- **WHEN** 老师问一个不在当前班级的学生
- **THEN** 拒绝并说明本班没有这个学生，不返回任何其他班数据

#### Scenario: 转出学生查不到

- **WHEN** 学生已经转出当前班级，但当前班还留有他的历史作答快照
- **THEN** 老师不能通过 Agent 读取该学生的考试摘要

#### Scenario: 同名需要补充信息

- **WHEN** 当前班级里有多个同名学生
- **THEN** 工具要求老师补充可区分的信息，不随便选一个返回

#### Scenario: 未判分没有摘要

- **WHEN** 学生已交卷但这次考试还没判分
- **THEN** 返回"还没有判分结果"，不返回 0 分或猜测分数

#### Scenario: 学生不能走老师路径

- **WHEN** 学生问另一个学生的考试结果
- **THEN** 拒绝，不返回任何他人数据
