# Spec Delta

## MODIFIED Requirements

### Requirement: 只能改自己建的
写操作 MUST 只作用于当前用户自己创建的对象，知识点词典的共享写入除外（见「知识点词典共享写入」）。建题 MUST 仅限老师与管理员，且创建时归属当前用户；对他人创建对象的写操作 MUST 拒绝并提示"不是这道题的创建者"。管理员不受本规则限制。

#### Scenario: 建题归属创建者
- **WHEN** 老师登录后建题
- **THEN** 这道题的创建者是这位老师

#### Scenario: 学生建题被拒
- **WHEN** 学生登录后请求建题
- **THEN** 拒绝（403），不创建任何题目

#### Scenario: 改别人的题被拒
- **WHEN** 老师请求修改另一位老师创建的题
- **THEN** 拒绝，提示"不是这道题的创建者"

#### Scenario: 管理员不受创建者归属限制
- **WHEN** 管理员请求修改任一老师创建的题
- **THEN** 允许

## ADDED Requirements

### Requirement: 知识点词典共享写入
知识点是全校共享的教学词典。任何老师 MUST 能创建知识点、修改任意知识点的名称与别名、把任意知识点合并到另一个知识点，MUST NOT 因不是创建者而被拒绝。题目与知识点的挂载仍 MUST 遵守题目归属：老师只能修改自己创建的题的关联，MUST NOT 修改他人的题。管理员不受创建者与归属限制；学生 MUST 返回 403。

#### Scenario: 老师改他人建的知识点
- **WHEN** 老师修改另一位老师创建的知识点的别名
- **THEN** 允许，修改生效

#### Scenario: 老师合并他人建的知识点
- **WHEN** 老师把另一位老师创建的知识点合并到自己的知识点
- **THEN** 允许，合并生效

#### Scenario: 老师挂他人的题被拒
- **WHEN** 老师尝试修改另一位老师创建的题的关联
- **THEN** 返回 403，关联不变

#### Scenario: 管理员可改任意关联
- **WHEN** 管理员修改任一老师创建的题的关联
- **THEN** 允许

#### Scenario: 学生不能写知识点
- **WHEN** 学生请求创建、修改或合并知识点
- **THEN** 返回 403，不修改数据
