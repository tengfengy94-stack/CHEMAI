# Spec Delta

## MODIFIED Requirements

### Requirement: 错误率口径

错误率 MUST 等于错题数除以作答数。统计 MUST 读已判分考试的逐题作答和练习记录两处，每条作答各算一次；同一道题答三次错两次时，分子 MUST 是 2，分母 MUST 是 3。一道题属于多个知识点时，MUST 在每个知识点的分子分母里各算一次。没有关联知识点的题、未判分记录、复习作答 MUST NOT 进入统计。练习记录 MUST 按它作答的那道题关联的知识点计入。

#### Scenario: 同一题多次作答各算一次
- **WHEN** 学生对一道题答了三次、错两次
- **THEN** 这道题所属知识点的作答数是 3，错题数是 2

#### Scenario: 一题多知识点各算一次
- **WHEN** 一道同时属于两个知识点的题答错了
- **THEN** 两个知识点各自的错题数都加 1，作答数也都加 1

#### Scenario: 未挂知识点的题不计
- **WHEN** 学生答错一道没有关联任何知识点的题
- **THEN** 任何知识点的错误率都不变

#### Scenario: 未判分记录不计
- **WHEN** 一条作答记录停在已交卷且分数为空
- **THEN** 它的逐题作答不进入任何知识点的分子或分母

#### Scenario: 复习作答不计
- **WHEN** 学生在复习里答错一道题
- **THEN** 任何知识点的错误率都不变

#### Scenario: 未作答按错计入
- **WHEN** 学生交白卷，卷内每道题都记了空答案并按错判
- **THEN** 这些题按错题计入各自知识点

#### Scenario: 练习答错计入
- **WHEN** 学生练习时答错一道挂着知识点的题
- **THEN** 该知识点的作答数加 1，错题数加 1

#### Scenario: 练习答对计入分母
- **WHEN** 学生练习时答对一道挂着知识点的题
- **THEN** 该知识点的作答数加 1，错题数不变

#### Scenario: 考试与练习合并计数
- **WHEN** 学生对同一知识点先考试答错一次、再练习答对一次
- **THEN** 该知识点的作答数是 2，错题数是 1，错误率是 50%

#### Scenario: 练习未挂知识点不计
- **WHEN** 学生练习一道没有关联任何知识点的题
- **THEN** 任何知识点的错误率都不变

### Requirement: 弱项前三与样本门槛

弱项排名 MUST 只计算作答数不少于 2 的知识点；作答数 MUST 按考试逐题作答与练习记录合并计算。排序 MUST 先按错误率降序，错误率相同时按作答数降序，再相同时按知识点 ID 升序；最多 MUST 返回 3 个。错误率 MUST 以百分比返回并保留一位小数；每条 MUST 含知识点 ID、名称、作答数、错题数和错误率。

#### Scenario: 样本不足不进排名
- **WHEN** 一个知识点只有 1 次作答且答错
- **THEN** 它的错误率虽是 100%，但不进入弱项排名

#### Scenario: 样本够但全对不占前三
- **WHEN** 一个知识点有 2 次作答且全对，另外三个知识点的错误率都高于 0
- **THEN** 这个知识点不进入前三

#### Scenario: 错误率相同按作答数排
- **WHEN** 两个知识点的错误率相同，一个作答 8 次、一个作答 4 次
- **THEN** 作答 8 次的排在前面

#### Scenario: 最多三个
- **WHEN** 五个知识点的作答数都达到门槛
- **THEN** 只返回错误率最高的三个

#### Scenario: 百分比一位小数
- **WHEN** 一个知识点作答 3 次、错 2 次
- **THEN** 错误率返回 66.7

#### Scenario: 考试与练习合起来达到门槛
- **WHEN** 一个知识点在考试里作答 1 次、在练习里作答 1 次
- **THEN** 作答数是 2，达到样本门槛

### Requirement: 无数据状态

学生既没有任何已判分的逐题作答、也没有任何练习记录时，弱项接口 MUST 返回 `has_data` 为 false 和空列表，页面 MUST 显示「还没有学习记录」，MUST NOT 显示掌握度 0 或分数 0。学生有已判分作答或练习记录、但没有知识点达到样本门槛时，MUST 返回 `has_data` 为 true 和空列表，页面 MUST 显示「暂无可统计的弱项」，MUST NOT 显示「还没有学习记录」。

#### Scenario: 新学生没有学习记录
- **WHEN** 一个还没有考过试、也没有练习过的学生请求弱项
- **THEN** 返回 has_data=false 和空列表

#### Scenario: 只有练习记录也算有学习记录
- **WHEN** 一个没有考试记录、但练过题的学生请求弱项
- **THEN** 返回 has_data=true，并按练习记录计算弱项

#### Scenario: 有作答但没挂知识点
- **WHEN** 学生考过试或练过题，但作答的题都没有关联知识点
- **THEN** 返回 has_data=true 和空列表，页面显示「暂无可统计的弱项」

#### Scenario: 有作答但样本不足
- **WHEN** 学生只做过一道题（考试或练习），且它关联的知识点作答数不到 2
- **THEN** 返回 has_data=true 和空列表，不把 100% 当成弱项

### Requirement: 合并后重算

弱项 MUST 每次请求现算，MUST NOT 读缓存或存快照。知识点合并后再次请求，MUST 按合并后的目标知识点重新汇总；合并前的源知识点 MUST NOT 再出现在结果里。练习记录 MUST 按合并后的题目关联重新计入，MUST NOT 重复或丢失。

#### Scenario: 合并两个知识点后重算
- **WHEN** 两个知识点各有一些作答，老师把它们合并成一个，然后学生刷新弱项
- **THEN** 两个知识点的作答数与错题数合并在目标知识点下，源知识点不再出现

#### Scenario: 合并后练习记录重新计入
- **WHEN** 两个知识点各有考试与练习作答，老师把它们合并成一个
- **THEN** 目标知识点的作答数与错题数包含两边的考试和练习记录，没有重复行
