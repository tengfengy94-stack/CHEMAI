# Spec Delta

## MODIFIED Requirements

### Requirement: 删除题目

只有创建者 MUST 能删除题目，管理员不受限制。被任何卷子使用过的题 MUST 拒绝删除并给出使用份数；被任何练习记录引用过的题 MUST 拒绝删除并说明已被学生练习过；只有既未被卷子使用、也未被练习记录引用的题 MUST 可删除。删除成功后该题 MUST 不再出现在题库列表与详情中。

#### Scenario: 删除未被使用的题
- **WHEN** 老师删除一道没有进过任何卷子、也没有被练习过的草稿题
- **THEN** 删除成功，列表里不再出现

#### Scenario: 被卷子使用的题被拒
- **WHEN** 老师删除一道已被卷子使用的题
- **THEN** 拒绝，提示"这道题已被几份卷子使用"

#### Scenario: 被练习记录引用的题被拒
- **WHEN** 老师删除一道没有进过卷子、但已被学生练习过的题
- **THEN** 返回 409，提示这道题已被学生练习过，题目与练习记录都保留

#### Scenario: 练习记录不随删题消失
- **WHEN** 老师尝试删除一道被学生练习过的题
- **THEN** 这道题的练习记录与它在弱项统计里的作答数、错题数都不变

#### Scenario: 非创建者删除被拒
- **WHEN** 另一位老师尝试删除不是自己建的题
- **THEN** 拒绝，提示"不是这道题的创建者"
