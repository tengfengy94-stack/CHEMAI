# Proposal

## Why

第 07 章为弱项统计做了知识点的后端最小闭环：建、改、树读取、合并都有了，但没有管理页；开发库里的知识点是验收走查时临时调接口写进去的，既没有正式词表，也无法在界面上维护。第 08 章把知识点升级为老师可维护的知识图谱，并把上一章的临时标签迁进正式分类后删除。

## What Changes

- **老师端知识点管理页**：新增 `/teacher/knowledge`，用两层树展示名称、别名与直接题目数；支持建根节点、建子节点、改名称/别名、合并节点。合并目标只允许合法节点（不能是源自己或源的下级；源有子节点时不能并进子节点，避免第三层），确认框写明别名、题目关联和子节点会移到目标。页面覆盖加载、空、正常、出错四态，空树显示"还没有知识点"并提供"新建第一个知识点"。老师页头增加"知识点"入口。
- **正式知识词表**：定义一套两层正式词表——根节点为氧化还原、电化学、化学平衡、物质结构、元素周期律；氧化还原下为氧化剂、还原剂。名称与别名沿用现有全局唯一规则。
- **临时标签迁移**：新增一次性、幂等、支持 dry-run 的迁移命令。把第 07 章遗留的临时知识点按名称或别名映射到正式词表：命中时沿用现有合并语义，把别名、题目关联、子节点并入正式节点并删除临时源节点；未命中的临时节点保留并提升为正式根节点，写进迁移报告，不静默删除。迁移后弱项统计按合并后的正式节点重新汇总。
- **测试与验收**：补迁移测试（命中归并、别名与题目关联去重、未命中保留、重复执行、dry-run 不写库）和老师管理页四态走查；跑全量 pytest、`bash scripts/check.sh 08`、`bash scripts/doctor.sh`、`npm run lint && npm run build`。
- **不在本次范围**：三级及以上层级、跨分支前置/相关关系、知识点删除接口、学生端知识点浏览、题目按知识点筛选、自动合并近义词、AI 工具。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `knowledge-map`: 增加老师端知识点管理页的可观察行为；规定正式两层词表，以及第 07 章临时知识点在升级时 MUST 归并进正式词表并删除被合并的源节点，无法映射的 MUST 保留并报告；迁移 MUST 幂等。

## Impact

- **后端**：新增正式词表与迁移模块（`backend/app/knowledge_seed.py`、`backend/app/knowledge_migrate.py`）；把 `knowledge.merge_points` 的事务提交拆成可复用的内部函数，供迁移把多次合并放进一个事务。管理页复用现有 4 个知识点接口，不新增表、不新增接口。
- **前端**：`api.js` 增加知识点树、建节点、改节点、合并节点四个封装；新增 `pages/teacher/Knowledge.jsx`；`App.jsx` 增加路由；题库页与考试页的页头增加"知识点"入口。
- **数据**：开发库 `chemai.db` 的临时知识点按映射归并，题目关联随源节点转移到正式节点，弱项统计口径不变。测试库继续由 pytest 每用例临时建库。
- **接口契约**：继续使用 `{success, data, error}` 信封；现有知识点接口的字段和语义不变。
- **依赖**：不新增第三方依赖。
