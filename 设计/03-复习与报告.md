# 03 复习与报告

---

## 一、这个模块解决什么问题

周一的讲评课上完，学生知道了自己错了哪几道，老师知道了这套卷子哪几道错得多。然后就没有然后了：错题本躺在那里，没人再打开；下次考试，同样的地方再错一遍。

老师这边也一样。班级平均分 72，这个数字说明不了下一步该做什么——是氧化还原不行，还是计算题不行？是全班都弱，还是几个人拖下来的？

这条链上有三个地方会断：

| 断在哪 | 后果 |
|---|---|
| 错题只是列出来，没有下一步 | 学生不知道今天该看哪几道，最后一道都不看 |
| 练习不分难度、不分人 | 给弱项学生出最难的题，连错三题就关掉页面 |
| 同一个知识点三种叫法 | 统计被拆成三条，老师看不出真正的弱项 |

这个模块做三件事：把错题排到未来的某一天，按学生的水平出练习题，把已有的数据按一个固定的口径算成人能看的数字。

它不判分，也不产生题目。判分和题目都是题库与考试的事，这里只消费它们的结果。

---

## 二、核心概念与它们的关系

四个概念，一个是时间，一个是难度，一个是归类，一个是视图。

```
考试判分 ──错题──→ 复习任务 ──答对升级──→ 到期 / 出队
     │                  ↑
     ├──逐题对错──┐      │
     │            ├──→ 知识点 ──→ 弱项 ──→ 报告
     └──练习记录──┘      │
                         └──→ 练习选题
```

| 概念 | 一句话 | 谁产生 |
|---|---|---|
| 复习任务 | 哪个学生对哪道题、复习到第几级、下次什么时候 | 判分时系统建，学生可以手动加 |
| 练习记录 | 哪个学生练了哪道题、当时给的哪档难度、对还是错 | 学生每答一道建一条 |
| 知识点 | 这道题属于哪个知识范围，同一个范围的几种叫法归到一处 | 老师建、老师合并 |
| 报告 | 把上面三样和考试成绩按口径算出来的几个数字 | 每次打开时现算 |

**复习是系统里唯一带时间的线。** 其余数据都是"发生过什么"，只有复习任务回答"接下来哪天做什么"。这条线一断，错题本就退回成一张清单。

**错题和复习任务不是一回事。** 错题是"这道题错过"，复习任务是"这道题哪天再做一次"。一道题在错题本里待着，可能已经不用复习了；一道题从复习队列出队，也不代表它没在错题本里。两个概念分开，是因为它们回答的问题不同：一个回答过去，一个回答将来。

**报告没有自己的数据。** 它是把作答、练习、复习按某个口径算出来的一个视图，每次打开现算。存一份报告，口径一改，旧的那份就和新的对不上，还说不清哪份才对。

## 三、正常流程：谁在什么时候做什么

| 步骤 | 谁 | 什么时候 | 系统做什么 |
|:--:|---|---|---|
| 1 | 系统 | 判分完成时 | 每道错题建一条复习任务，第 0 级，明天到期 |
| 2 | 学生 | 每天打开复习页 | 列出今天及以前到期的，按到期时间排 |
| 3 | 学生 | 答一道复习题 | 判分；答对升一级，答错回 0 级；重算到期日 |
| 4 | 学生 | 打开练习页 | 从弱项知识点里挑一道，按当前难度 |
| 5 | 学生 | 答一道练习题 | 判分，记一条练习记录；连对够两题就升难度，答错就降 |
| 6 | 学生 | 打开报告页 | 算弱项前三、掌握度、最近五次分数、待复习数 |
| 7 | 老师 | 打开班级页 | 算全班的知识点错误率、每个学生的最近分数和错题数 |

一次错题走完复习全程的时间线：

| 时间 | 发生了什么 | 这条任务的级别 | 下次到期 |
|---|---|:--:|---|
| 周一 | 考试判分，这道题错了 | 0 | 周二 |
| 周二 | 复习，答对 | 1 | 周五（3 天后） |
| 周五 | 复习，答对 | 2 | 下周五（7 天后） |
| 下周五 | 复习，答对 | 3 | 两周后（14 天） |
| 两周后 | 复习，答对 | 4 | 一个月后（30 天） |
| 一个月后 | 复习，答对 | 5 | 出队，不再出现 |
| 再往后 | 考试又错了这道题 | 0 | 第二天 |

中途只要答错一次，就回到第 0 级，从明天重新开始。

两个对象的流转：

```
复习任务   第 0 级 ──答对──→ 第 1 级 ──→ … ──→ 第 5 级出队
              ↑                  │
              └──────答错────────┘

练习难度   1 档 ←──答错── 2 档 ──连对两题──→ 3 档
             └────────连对两题───────────────→ 3 档
```

练习难度只有三档。从 2 档起步，是因为中间起步两边都能动；从 1 档起步，第一次答错就没地方降了。

## 四、规则与判定

### 4.1 错题什么时候进复习队列

判分完成时，凡是答错的题，每道建一条复习任务，从第 0 级开始，明天到期。

第 0 级到第 5 级，每一级对应一个间隔：

| 级别 | 下次间隔 |
|:--:|---|
| 0 | 1 天 |
| 1 | 3 天 |
| 2 | 7 天 |
| 3 | 14 天 |
| 4 | 30 天 |
| 5 | 出队 |

答对升一级，下次到期 = 本次作答时间 + 新级别的间隔。答错回 0 级，明天再来。

**同一道题再考错，级别归零，不新增一条。** 一个学生对一道题只有一条复习任务。已经出队的题再考错，重新入队，还是从 0 级开始。

**第 5 级是出队，不是删除。** 任务留着，只是不再出现在到期列表里。删了就回答不了"这道题我复习过几次"。

**只列今天及以前到期的。** 按到期时间升序，逾期的排最前面。逾期不清零、不降级、不标红——晚了两天再做，效果不如按时，但比不做强，没有必要因为晚了两天把进度抹掉。

为什么是这六级：1、3、7、14、30，覆盖一个月里五次接触。再加级，对高中教学没有区别；减级，30 天这一档就没了。

### 4.2 复习怎么答

一题一屏。先给题目和选项，不给标准答案。

学生重新作答，提交后系统判分，用的是题库与考试那一套比较规则，不另写一套。判完显示：学生的答案、标准答案、解析、上次的答案。

**不让学生自己点"对了""错了"。** 自评会松：看着眼熟就算会，想不起细节也算会。系统判分跑不掉，而且和考试用的是同一把尺子，复习时说"我会了"、考试时写错，这种事不会发生。

复习答错的题，回到第 0 级，明天再出现。学生也可以让 AI 手动把一道题加进复习队列，那是 Agent 的工具，规则一样：一条任务，从 0 级开始。

### 4.3 练习出什么题

练习不限次数，学生想练就练。每答一道，记一条练习记录：哪道题、当时给的哪档难度、对还是错。

**选题范围**：学生弱项前三的知识点下面的题，只取已通过的。

**排除**：最近 20 条练习记录里出现过的题。排除要在难度筛选之前做，做完再按难度挑；顺序反了，就会反复出同一道题。

**难度**：从 2 档起步。连续答对两题升一档，最高 3 档；答错一题降一档，最低 1 档。连续答对几题从练习记录里数，不放在内存里——刷新页面、换个设备，计数还得在。

**没有候选时，按顺序放宽**：先在同一个知识点里放宽难度，任取一道；还是没有，把排除窗口从 20 条缩到 10 条、5 条、0 条；全都试过还是没有，才提示"该知识点暂无题"。不白屏，也不从别的地方随便抓一道充数。

只放宽难度、不放宽排除，会把小题库练死：一个知识点只有三道题，练满二十条之后三道全在排除窗口里，候选为空；没有新记录，窗口也不会往前滑，这个点就永远练不了了。宁可重复，不要死锁。

**新学生没有弱项时**：按中间难度随机出题，并提示"先做几道题，系统才能找到你的弱项"。没考试记录就没有统计，这是正常状态，不是错误。

**练习答错不进复习队列。** 练习是当场强化，错一道就进队列，队列会膨胀到没人看得完。进队列的是考试错题——考试错了，说明这个点真的没掌握。

复习和练习面对的东西不同：复习面对"错过的那一道题"，练习面对"弱的那个范围"。一道题复习到出队，不代表这个范围就稳了；一个范围里没考过的题，也能拿出来练。两条线各管一段，不互相替代。

### 4.4 知识点怎么归

知识点只有两层：学科大点，和它下面的具体点。氧化还原在上一层，氧化剂、还原剂在下一层。

每个知识点有名字和一组别名。别名的用处是收拢不同写法：同一个点，有人写"氧化还原"，有人写"氧化还原反应"，甚至有人写缩写，都该归到一处。一道题可以属于多个知识点。

**合并**：把一个知识点并进另一个。别名并过去，题目的关联并过去，子节点改挂到目标，源节点消失。合并之后，历史统计按目标节点重新算，不保留源节点的数据——合并不是删除，是改正：之前把一个点算成了三个，那三个数字本来就是错的。

**合并要检查方向。** 目标不能是自己，也不能是自己的下级。把上级并进下级，子节点改挂时会转出一个环，树就坏了。这种合并要拒绝。

**层级只有两层，所以"前置"就是上级，"后继"就是下级。** 不推整棵树，也不做跨分支的先修关系。学生对"学这个之前要先会什么"的答案，就是上一层那个范围。

**系统不自动合并近义词。** 合并是老师的判断，不是系统的猜测。猜错一次，要拆回来。

**没关联知识点的题不进弱项统计。** 它照样在错题本里、照样能复习，但它不参与"哪个知识点弱"的计算。统计只对归了类的题负责。

### 4.5 数字怎么算

**错误率 = 错题数 ÷ 作答数。** 只算作答数不少于 2 的知识点，取错误率最高的三个作为弱项。

数据来源是考试逐题作答和练习记录两处合并。同一道题答了三次错两次，分子是 2，分母是 3。

**复习的作答不进这个口径。** 复习测的是"同一道题隔几天还记不记得"，考试和练习测的是"遇到一道没见过的题会不会"。两件事混在一起，错误率就说不清是记不住还是没学会。复习的进步看在待复习数和级别上，不看错误率。

为什么要求作答数不少于 2：一道题错一次就是 100%，它的信息量和十道错七道差得远。样本不够的，不进排名，不是因为它不重要，是因为它还没资格说明问题。

| 知识点 | 作答数 | 错题数 | 错误率 | 进不进弱项 |
|---|:--:|:--:|:--:|---|
| 氧化还原 | 8 | 5 | 62.5% | 进 |
| 电化学 | 6 | 3 | 50.0% | 进 |
| 化学平衡 | 4 | 2 | 50.0% | 进 |
| 物质结构 | 1 | 1 | 100% | 不进，样本不够 |
| 元素周期律 | 2 | 0 | 0% | 不进，没到前三 |

最后一行是"数据够、但没错"，它照样参与掌握度的计算，只是不会成为弱项。

**掌握度 = 知识点平均正确率 × 100。** 同样只算作答数不少于 2 的知识点。没有数据时返回 0，同时带上"没有数据"的标记——页面上显示"还没有学习记录"，不是显示"掌握度 0"。

**最近五次分数**：按判分时间取最近五次已判分的考试，按时间正序排。已交卷但没判分的不算。

**班级弱项分布**：把一个班所有学生的作答合在一起算错误率，不是把每个人的错误率平均。按人平均会让只做了一道题的学生和做了三十道题的学生权重一样大。

**班级按"发布时发给的那个班"算。** 学生后来转班，那次考试的统计不变。按学生现在在哪个班去归集，会让一次考试的数字在转班之后悄悄变掉。

**待复习数**：今天及以前到期的任务条数。

**合并之后重算**：所有统计都读知识点关联，不读任何缓存。合并完刷新，数字跟着变。

### 4.6 报告给谁看什么

**学生报告**：弱项前三、掌握度、最近五次分数的走势、待复习数。

**班级报告**：先按考试看，再按知识点看。

- **按考试**：选一次考试，给出提交情况（已交卷、作答中、还没开始）和逐题正确率。这是讲评课的入口——谁没交、哪道题错得多，一眼能看到。
- **按知识点**：全班的知识点错误率分布、每个学生的最近一次分数和错题数、这个班考过几次。

**报告每次现算，不存快照。** 打开时算一遍，数据变了下次打开就是新的。存快照要多一套"什么时候该重算"的规则，而且口径一改，旧快照就成了错的。

**没有数据的学生，报告显示"还没有学习记录"。** 不显示 0 分，不显示空图表。0 分是考了没得分，没数据是还没考过，两件事。

权限：学生只能看自己的报告，老师只能看自己带的班的报告。这两条落在权限模块的三条规则上，这里只交代结果。

## 五、边界与异常

| 谁 | 情况 | 系统怎么反应 |
|---|---|---|
| 学生 | 今天没有到期的复习 | 空列表，提示"今天没有要复习的" |
| 学生 | 一条任务逾期了一周 | 仍然列出，排在最前，级别不动 |
| 学生 | 复习时答错 | 回 0 级，明天再出现 |
| 学生 | 一道题复习到出队，考试又错 | 回 0 级重新入队，不新增任务 |
| 学生 | 同一道题今天答了两次 | 只有一条任务，第二次照常判、照常升级 |
| 学生 | 新账号，没有考试记录 | 练习按中间难度随机出题；报告显示"还没有学习记录" |
| 学生 | 弱项知识点下没有题 | 提示"该知识点暂无题"，不白屏 |
| 学生 | 看别人的报告 | 拒绝，不返回数据 |
| 老师 | 把知识点合并到自己 | 拒绝 |
| 老师 | 把上级并进自己的下级 | 拒绝，会转成环 |
| 老师 | 合并一个已经不存在的节点 | 找不到，不报 500 |
| 老师 | 看别的班的报告 | 拒绝 |
| 老师 | 一个学生一道题都没做 | 班级表格里显示"未作答"，不当成 0 分 |

**逾期不惩罚。** 一个学生一周没打开系统，回来看到七条逾期，如果发现级别掉了，下次就不敢打开了。级别只由答对答错决定，不由时间来定。

**没有数据的班不显示 0。** 新建的班、还没考过试的班，班级页显示"还没有考试记录"。0 分和没考过是两件事，混在一起，老师会以为全班考砸了。

**一道题属于两个知识点，它的作答在两个知识点的分母里各算一次。** 这是有意的：这道题确实同时考了两个点，在两边都应该被算到。代价是两个知识点的错误率不能相加。

**未判分的卷子不进任何统计。** 交卷了但判分失败的那条记录，分数是空的；报告跳过它，不按 0 分算。

## 六、与其他模块的接口

| 我提供给谁 | 提供什么 |
|---|---|
| Agent | 学生画像：弱项前三、掌握度、最近五次分数、待复习数；今天到期的复习清单；按知识点查题的能力 |
| 页面与选型 | 五个页面要的数据：复习、练习、学生报告、班级报告、知识点 |

| 我依赖谁 | 依赖什么 |
|---|---|
| 题库与考试 | 判分结果、提交状态、错题清单、每道题的对错、**判分规则**、题目的难度和审核状态 |
| 数据与权限 | 学生只能看自己的、老师只能看自己带的班 |

**判分规则是借来的，不是这里写的。** 复习作答、练习作答，都用题库与考试那一套比较规则。这里再写一份，就会出现"考试判错、复习判对"，而这种错只能靠对数据发现。

**错题从题库与考试来，复习任务从这里开始。** 判分只说"这道题答错了"；排到哪天、升几级、什么时候出队，是这一模块的事。这个分工让题库与考试不需要知道"时间"这件事。

**学生画像是这一模块给 Agent 的主要东西。** Agent 说"你氧化还原错了三次"，那个"三次"必须来自这里的一次查询，不能来自模型记住的对话。

## 七、取舍

| 放弃了什么 | 为什么 |
|---|---|
| 按个人记忆曲线调参 | 固定六级间隔。调参要几百条个人数据才稳，一个班几周的数据不够，算出来的是噪声 |
| 练习错题进复习队列 | 练习是当场强化，全进队列会让队列膨胀到没人看得完。进队列的只有考试错题 |
| 自动合并近义知识点 | 合并是判断不是计算，猜错一次要拆回来。系统只提供合并动作，不替老师决定 |
| 知识点无限层级 | 两层够找弱项。三层以上对"哪个点弱"没有额外信息 |
| 班级排名 | 排名会改变学生和老师的使用方式，而且容易被误读成"这个学生不行" |
| 报告快照 | 每次现算。存快照要一套重算规则，口径一改旧快照就是错的 |
| 预警与推送 | 只在页面上展示。推送要处理渠道、频率、退订，与核心闭环无关 |
| 掌握度的严格标定 | 0 到 100 是一个相对指数，不是"掌握了 73%"这种测量。它只用来比较同一个学生的不同知识点 |
| 练习历史页 | 练习记录只用来选题和统计，不给学生看流水账 |
| 复习任务的撤销 | 学生不能手动把一条任务移出队列；要它消失，就答对到第 5 级 |
| 复习作答不计入错误率 | 复习测的是同一道题的间隔回忆，和新题上的表现不是一回事；进步看待复习数和级别 |
| 转班不重算历史 | 班级统计按发布时发给的班算，转班不改写已经发生的考试 |
